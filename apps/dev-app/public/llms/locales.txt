# @oge-ui/locales

> Ready-made translations of every message catalog — German, French, Spanish, Italian, Brazilian Portuguese, Turkish, Japanese, Simplified Chinese, Arabic, Hebrew and Russian — as framework-free data, one entry point per language (`import { tr } from '@oge-ui/locales/tr'`). Applied with `provideOgeLocale(tr)` from `oge-ui` or `<OgeLocaleProvider pack={tr}>` from `@oge-ui/react`; commercial families take `ogeMergeMessages(OGE_DEFAULT_<X>_MESSAGES, tr.<x>)` through their own provider.

Part of OGE UI v1.1.8.
Docs and live demos: https://www.ogeui.com/getting-started/localization
Whole-suite reference: https://www.ogeui.com/llms-full.txt

```sh
npm i @oge-ui/locales
```

## Using this package

These are **translation packs** — plain data, imported directly by apps.

1. **Import one language from its own entry point**:
   `import { tr } from '@oge-ui/locales/tr'` (`de fr es it pt-BR tr ja zh-CN ar he`;
   the export is the code, `pt-BR` → `ptBR`, `zh-CN` → `zhCN`). The primary entry
   `@oge-ui/locales` carries no translations — only types, `ogeMergeMessages`,
   `OGE_LOCALE_NAMES`, the `en` baseline and the lazy `ogeLocalePacks` map.
2. **Angular**: `provideOgeLocale(tr)` from `oge-ui` configures every MIT family
   (strings + `locale`). **React**: `<OgeLocaleProvider pack={tr}>` from
   `@oge-ui/react`. Never spread a pack into one family's config by hand —
   use `ogeMergeMessages(OGE_DEFAULT_<X>_MESSAGES, tr.<x>)`, because the family
   resolvers replace nested blocks (`operators`, `toolbar`, …) whole.
3. **Runtime switching**: the live form `provideOgeLocale(() => pack())` with
   `pack.set(await ogeLocalePacks[code]())`; in React, pass a new `pack`.
4. **Commercial families** (pivot, scheduler, Gantt, Kanban, BPMN, charts) are
   not wired by the MIT umbrellas: pass
   `ogeMergeMessages(OGE_DEFAULT_SCHEDULER_MESSAGES, tr.scheduler)` (and so on) to
   their own provider.
5. **The app owns `LOCALE_ID` and the page's `dir`** — set them from
   `pack.locale` / `pack.dir` (`ar` and `he` are `'rtl'`).

## API reference

### Locale wiring

#### Properties

| Name | Type | Description |
| --- | --- | --- |
| `provideOgeLocale(pack)` | `(pack: OgeLocalePack \| (() => OgeLocalePack)) => Provider[]` | From `oge-ui`. Provides every MIT family’s config — grid / tree list, inputs, buttons, overlay, tabs, forms, upload, the layout and navigation components — with the pack’s slice merged over the English catalog, plus the pack’s `locale` for the grid and the editors. A function makes it live: the language follows the signals it reads. It owns those config tokens — provide a family’s own config after it to change other options. `LOCALE_ID` and the page’s `dir` stay the app’s job; commercial families take their slice through their own providers. |
| `pack` | `OgeLocalePack \| (() => OgeLocalePack)` | The pack to apply — a static pack, or a function reading a signal for runtime switching (`provideOgeLocale(() => pack())`). |
| `provideOgeGridLocale(pack)` | `(pack: OgeLocalePack \| (() => OgeLocalePack)) => Provider[]` | The grid slice of `provideOgeLocale` — the grid and tree list catalogs and data locale — for an app that ships only some families: each slice bundles only its own catalogs (the full call bundles all). Same merge rule and live form. |
| `provideOgeInputsLocale(pack)` | `(pack: OgeLocalePack \| (() => OgeLocalePack)) => Provider[]` | The inputs slice of `provideOgeLocale` — every editor of the inputs family, with its data locale — for an app that ships only some families: each slice bundles only its own catalogs (the full call bundles all). Same merge rule and live form. |
| `provideOgeButtonsLocale(pack)` | `(pack: OgeLocalePack \| (() => OgeLocalePack)) => Provider[]` | The buttons slice of `provideOgeLocale` — buttons and the floating action button — for an app that ships only some families: each slice bundles only its own catalogs (the full call bundles all). Same merge rule and live form. |
| `provideOgeOverlayLocale(pack)` | `(pack: OgeLocalePack \| (() => OgeLocalePack)) => Provider[]` | The overlay slice of `provideOgeLocale` — modal, popover, tooltip, context menu, toast, window and action sheet — for an app that ships only some families: each slice bundles only its own catalogs (the full call bundles all). Same merge rule and live form. |
| `provideOgeTabsLocale(pack)` | `(pack: OgeLocalePack \| (() => OgeLocalePack)) => Provider[]` | The tabs slice of `provideOgeLocale` — the tabs family — for an app that ships only some families: each slice bundles only its own catalogs (the full call bundles all). Same merge rule and live form. |

Same merge rule and live form. |

Same merge rule and live form. |

_Primary entry (@oge-ui/locales)_

| Name | Type | Description |
| --- | --- | --- |
| `en` | `OgeLocalePack` | The English baseline — `{ locale: 'en', dir: 'ltr' }` with no slices, so every catalog keeps its built-in strings. Switch back to it like to any other pack. |
| `ogeLocalePacks` | `Readonly<Record<OgeLocaleCode, () => Promise<OgeLocalePack>>>` | Lazy loaders, one dynamic `import()` per language entry — a language switcher downloads only the packs a user picks. |
| `OGE_LOCALE_NAMES` | `Readonly<Record<OgeLocaleCode, string>>` | Each language’s own name (`Deutsch`, `日本語`, `العربية`…) — the labels of a switcher. |

#### Methods

| Name | Type | Description |
| --- | --- | --- |
| `ogeMergeMessages(defaults, slice)` | `<T extends object>(defaults: T, slice: OgeDeepPartial<T> \| undefined) => T` | Lays a pack slice over a complete catalog, nested blocks key by key — every key the slice lacks keeps the English string. Use it to hand a slice to a family provider yourself (commercial families, or a family whose other options you also set): `messages: ogeMergeMessages(OGE_DEFAULT_SCHEDULER_MESSAGES, tr.scheduler)`. |

#### Types

| Name | Type | Description |
| --- | --- | --- |
| `OgeLocalePack` | `{ locale; dir: 'ltr' \| 'rtl'; grid?; inputs?; buttons?; overlay?; tabs?; forms?; upload?; layout?; navigation?; pivot?; scheduler?; gantt?; kanban?; bpmn?; charts? }` | One language: the BCP 47 `locale` for `Intl` formats, the writing direction and a deep-partial slice per message catalog. The tree list reads the grid’s catalog, so `grid` covers both. The commercial slices are typed with `import type` from the engines — erased by the build, so the MIT package has no runtime dependency on them. |
| `OgeLocaleLayoutMessages` | `{ accordion?; progressBar?; loadIndicator?; splitter?; toolbar? }` | The layout family’s catalogs, one per component. |
| `OgeLocaleNavigationMessages` | `{ breadcrumb?; drawer?; menubar?; pagination?; stepper?; treeView? }` | The navigation family’s catalogs, one per component. |
| `OgeDeepPartial<T>` | `mapped type` | Every key optional, nested blocks included — a key a newer release adds is simply missing from an older pack and falls back to English. |
| `OgeLocaleCode` | `'en' \| 'de' \| 'fr' \| 'es' \| 'it' \| 'pt-BR' \| 'tr' \| 'ja' \| 'zh-CN' \| 'ar' \| 'he'` | The languages this package ships, plus the English baseline. |
