# @oge-ui/ai

> AI components that work with any model — a natural-language grid assistant that turns a sentence into validated sort, filter, grouping, search and column changes, and smart paste that fills a form from copied text, both with preview, apply and undo; transports for your own backend, OpenAI-compatible servers (OpenAI, Azure, Ollama, vLLM) and Anthropic. No hosted service, no row data sent.

Part of OGE UI v1.1.6.
Docs and live demos: https://www.ogeui.com/components/ai
Whole-suite reference: https://www.ogeui.com/llms-full.txt

```sh
npm i @oge-ui/ai
```

## Writing OGE code

Follow these rules and generated code compiles on the first try.

1. **Standalone only.** There are no NgModules and no `Oge*Module` symbols.
   Import the component class and list it in the host component's `imports`
   array: `imports: [OgeGrid, OgeColumn]`.
2. **Signal APIs, never decorators.** Public members are `input()`,
   `input.required()`, `model()` and `output()` — not `@Input()`/`@Output()`.
   Read them as signals in TypeScript (`grid.selectedKeys()`).
3. **Two-way state is `model()`.** Bind with the banana box against a signal:
   `[(selectedKeys)]="keys"`. `ngModel` is supported by the editors in
   `@oge-ui/inputs` for reactive/template forms, but signal binding is the
   idiomatic form.
4. **Modes are string unions, never enums.** Write the literal:
   `selectionMode="multiple"`, `editMode="batch"`, `stylingMode="outlined"`,
   `severity="danger"`. There is no `OgeSelectionMode.Multiple`.
5. **Outputs are past tense with no `on` prefix** — `(rowClick)`,
   `(selectionChanged)`, `(savedChanges)`, `(clicked)`. Never `(onRowClick)`.
6. **`-ing` outputs are cancelable.** Events like `rowInserting`,
   `rowUpdating`, `rowRemoving`, `savingChanges`, `exporting`, the modal's
   `opening`/`closing` and the tab strip's `selectionChanging` carry a mutable
   `cancel: boolean` — set `event.cancel = true` to veto, and the matching
   past-tense event never fires.
7. **App-wide defaults and every user-facing string** come from a provider:
   `provideOgeGridConfig()`, `provideOgeInputsConfig()`,
   `provideOgeButtonsConfig()`, `provideOgeOverlayConfig()`,
   `provideOgeTabsConfig()`, `provideOgeAccordionConfig()`. Each takes a
   `messages` block — that is how localization works; there is no i18n
   dependency. Pass a function instead of an object
   (`provideOgeGridConfig(() => ({ messages: lang() === 'tr' ? TR : {} }))`)
   and the config is live: components re-render their strings when the signals
   it reads change, so the language switches without a reload.
8. **Styling is CSS custom properties**, all prefixed `--oge-`. Never target
   internal class names to change colors or sizing; override the token.
9. **Templates and slots are structural directives on the markup you want**,
   not `<ng-template>` wrappers:
   `<oge-column field="price"><span *ogeCellTemplate="let value">…</span></oge-column>`,
   `<div *ogeModalFooter>…</div>`.

### Theming

```css
:root {
  --oge-accent: #4f46e5;   /* selection, focus, primary actions */
  --oge-radius-lg: 10px;
  --oge-row-height: 32px;  /* grid & tree-list density */
}
```

Token defaults have zero specificity: a plain `:root` rule (or any class)
wins, and tokens cascade into subtrees. Optional stylesheets, imported once,
ship in `@oge-ui/core` (installed with every package; add it directly under
pnpm): `@oge-ui/core/themes/dark.css` (then `class="oge-theme-dark"` or
`data-oge-theme="dark"` on `<html>` or any subtree; `"auto"` follows
`prefers-color-scheme`, `oge-theme-light` marks a light island),
`@oge-ui/core/themes/tailwind.css` and `@oge-ui/core/themes/bootstrap.css`
(bridge `--oge-*` onto an existing design system).

## Common mistakes

Predictable wrong guesses, and what to write instead.

| Wrong | Right |
| --- | --- |
| `<oge-data-grid>` | `<oge-grid>` |
| `[dataSource]="rows"` | `[data]="rows"` |
| `import { OgeGridModule }` | no modules — `imports: [OgeGrid, OgeColumn]` |
| `@Input() foo` on an OGE component | `readonly foo = input<T>()` |
| `(onRowClick)` / `(onSelectionChanged)` | `(rowClick)` / `(selectionChanged)` |
| `selectionMode="[SelectionMode.Multiple]"` | `selectionMode="multiple"` |
| `<oge-grid-column>` | `<oge-column>` |
| `MatDialog` / `DialogService` | `<oge-modal>` or `OgeModalService.open()` |
| `MessageService` / `ToastrService` / `MatSnackBar` | `OgeToastService.show()` (plus `success/info/warning/error`) |
| `<oge-dropdown>` / `<oge-combobox>` | `<oge-select-box>` (`<oge-tag-box>` when multiple) |
| `::ng-deep .oge-grid-row { … }` | override a `--oge-*` token |
| importing a theme to get default styles | not needed — styles ship with the components |

### OgeGridAssistant — `<oge-grid-assistant>`

#### Properties

_Target and transport_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `target` | `OgeGridAssistantTarget \| null` | `undefined` | The grid to drive — an `OgeGrid` template reference (`[target]="grid"`), or any object with `state()`, `applyState()` and `describeColumns()`. |
| `transport` | `OgeAiTransport \| null` | `undefined` | Replaces the configured transport for this assistant. Without either, a request ends in the `noTransport` error. |

_Behaviour (undefined = config)_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `mode` | `OgeGridAssistantMode` | `'preview'` | `"preview"` asks before applying (Apply / Discard), `"apply"` applies at once. |
| `suggestions` | `readonly string[]` | `[]` | One-click prompts shown as chips until the first change is applied. |
| `capabilities` | `Partial<OgeGridAiCapabilities>` | `undefined` | Turns parts of the state off for the model (`{ columns: false }`), merged over the config. |
| `instructions` | `string` | `undefined` | Domain vocabulary appended to the system prompt (““open” means status 1”). |
| `columns` | `readonly OgeAiGridColumn[]` | `undefined` | Column descriptions to send instead of the grid’s own — add `description`s, or leave a column out to keep it from the model. |
| `locale` | `string` | `undefined` | BCP 47 locale of plurals, passed to the model as the user’s locale; falls back to the config, then `LOCALE_ID`. |
| `messages` | `OgeGridAssistantMessagesInput` | `undefined` | Per-instance string overrides, merged over the catalog. |
| `disabled` | `boolean` | `false` | Disables the field, the chips and every action. |

#### Methods

| Name | Type | Description |
| --- | --- | --- |
| `submit(text?)` | `(text?: string) => Promise<void>` | Sends the prompt — or `text`, which also becomes the prompt. Resolves when the reply is handled; never rejects (failures land in the status). |
| `apply()` | `void` | Applies the pending proposal (the Apply button). |
| `discard()` | `void` | Drops the pending proposal; the grid stays as it is. |
| `undo()` | `void` | Reverts the latest applied change, one step per call (up to `undoLimit`). |
| `cancel()` | `void` | Aborts the request in flight (the Stop button, Escape). |
| `reset()` | `void` | Clears the prompt, the proposal, the conversation and the undo history. |
| `focus()` | `void` | Moves focus to the prompt field. |

#### Events

| Name | Type | Description |
| --- | --- | --- |
| `applying` | `OgeGridAssistantApplyingEvent` | A change is about to reach the grid — set `cancel` to veto it (e.g. confirm a destructive filter). |
| `applied` | `OgeGridAssistantAppliedEvent` | A change was applied: `{ prompt, summary, snapshot, previousSnapshot, slices }` — log it, or persist `snapshot` as a saved view. |
| `undone` | `OgeGridAssistantUndoneEvent` | Undo restored the previous state. |
| `errorOccurred` | `OgeGridAssistantErrorEvent` | A request failed: `"no-transport"`, an `OgeAiError` code, or `"invalid-reply"`. |

#### Types

_Providers_

| Name | Type | Description |
| --- | --- | --- |
| `provideOgeAiConfig(config)` | `(config: OgeAiConfigInput \| (() => OgeAiConfigInput)) => Provider` | Sets the transport and the AI defaults for an application or a route; a function makes the config live (switch the language without a reload). |
| `OGE_AI_CONFIG` | `InjectionToken<OgeAiConfig>` | The token every AI component reads its defaults from. |

_Transports_

| Name | Type | Description |
| --- | --- | --- |
| `createOgeAiHttpTransport(options)` | `(options: OgeAiHttpTransportOptions) => OgeAiTransport` | Posts every `OgeAiRequest` as JSON to your endpoint (`{ url, headers?, credentials?, fetch? }`), which calls the model with a key the browser never sees and answers `{ "text": "…" }` or plain text. The production shape. |
| `createOgeOpenAiTransport(options)` | `(options: OgeAiOpenAiTransportOptions) => OgeAiTransport` | OpenAI Chat Completions and every compatible server — Azure OpenAI (`query: { "api-version": … }` + an `api-key` header), Ollama (`baseUrl: "http://localhost:11434/v1"`), vLLM, LM Studio, OpenRouter. `structuredOutput`: `"json_schema"` (default), `"json_object"` or `"none"`. |
| `createOgeAnthropicTransport(options)` | `(options: OgeAiAnthropicTransportOptions) => OgeAiTransport` | The Anthropic Messages API (Claude): system messages go to `system`, text blocks are joined. `{ model, baseUrl?, apiKey?, apiVersion?, maxTokens? }`. |
| `dangerouslyAllowBrowser` | `boolean` | Required by the vendor transports to send an `apiKey` from a browser — without it they reject with `code: "browser-key"`. A key in client code is readable by every visitor: prototypes and internal tools only. |
| `OgeAiTransport` | `{ complete(request: OgeAiRequest, options?: { signal?: AbortSignal }): Promise<OgeAiResponse> }` | The whole contract — implement it to plug in any provider or SDK. Requests are abortable; the assistant aborts on Stop and when a newer prompt supersedes an older one. |
| `OgeAiRequest` | `{ feature; messages: readonly OgeAiMessage[]; responseSchema?; responseName?; temperature?; maxTokens? }` | What a feature sends: `feature` (`"grid-assistant"`) lets a backend route or rate-limit, `responseSchema` is the JSON Schema of the reply. |
| `OgeAiResponse` | `{ text: string; usage?: { inputTokens?; outputTokens? } }` | The model’s reply as text (JSON text for a schema). |
| `OgeAiMessage` | `{ role: 'system' \| 'user' \| 'assistant'; content: string }` | One message of the conversation. |
| `OgeAiError` | `Error & { code: 'aborted' \| 'network' \| 'http' \| 'invalid-response' \| 'browser-key'; status? }` | What every built-in transport rejects with; `status` carries the HTTP status of `"http"` errors. |
| `OgeAiFetch` | `(input: string, init) => Promise<{ ok; status; headers; text() }>` | The `fetch` shape the adapters call — pass `fetch` in the options for tests or a custom client. |

| --- | --- | --- |

| `OgeAiGridColumn` | `{ field; caption; dataType; sortable; filterable; groupable; visible; values?; description? }` | What the model is told about a column — never row data. `values` are a lookup’s items (texts map back to values); `description` adds meaning (“net amount in EUR”). |

| `OgeGridAssistantAppliedEvent` | `{ prompt; summary; snapshot; previousSnapshot; slices }` | A change reached the grid. |
| `OgeGridAssistantUndoneEvent` | `{ summary; snapshot }` | Undo restored `snapshot`. |

#### Types

_Chat_

| Name | Type | Description |
| --- | --- | --- |
| `OgeChatMessage` | `{ id; role: 'user' \| 'assistant'; text; status?: 'error'; time? }` | One message. Rendered as text with preserved line breaks — never as HTML or Markdown. |
| `OgeChatSendingEvent` | `{ text; cancel: boolean }` | Cancelable: set `cancel` to keep a message out (moderation, a required login). |
| `OgeChatSentEvent / OgeChatReplyEvent` | `{ message: OgeChatMessage }` | A user message or an assistant reply entered the conversation. |
| `OgeChatErrorEvent` | `{ code: OgeAiErrorCode \| 'no-transport'; error }` | A reply failed; the failed turn shows a retry button. |
| `OgeChatConfig` | `{ instructions; historyLimit; suggestions }` | Defaults under `chat` in the AI config: the last 20 messages replayed to the model. |
| `OgeChatMessages` | `{ label; logLabel; composerLabel; placeholder; send; stop; retry; clear; you; assistant; thinking; error; emptyReply; empty; suggestions }` | Under `messages.chat`; every `@oge-ui/locales` pack carries them. |
| `OgeChatCore` | `class OgeChatCore { list; draft; thinking; canSend; send(); addMessage(); retry(); stop(); clear() }` | The shared machine both chats run (`@oge-ui/behavior`) — usable on its own for a custom chat UI. |

### Events

```ts
import { ChangeDetectionStrategy, Component, signal } from '@angular/core';
import { OgeGridAssistant } from '@oge-ui/ai';
import { OgeColumn, OgeGrid } from '@oge-ui/grid';
import type { OgeGridAssistantAppliedEvent, OgeGridAssistantApplyingEvent } from '@oge-ui/ai';

interface Order {
  id: number;
  customer: string;
  city: string;
  status: number;
  amount: number;
  ordered: Date;
}

@Component({
  selector: 'demo-root',
  imports: [OgeGridAssistant, OgeColumn, OgeGrid],
  changeDetection: ChangeDetectionStrategy.OnPush,
  template: `
    <!-- (applying) is cancelable — here, a change that would hide columns needs
         a confirmation. (applied) carries the full snapshot: save it as a view. -->
    <oge-grid-assistant
      [target]="grid"
      mode="apply"
      (applying)="guard($event)"
      (applied)="log.update((l) => [event($event), ...l])"
    />

    <oge-grid #grid [data]="orders" keyField="id">
      <oge-column field="id" caption="Order" dataType="number" [width]="90" />
      <oge-column field="customer" caption="Customer" />
      <oge-column field="city" caption="City" />
      <oge-column
        field="status"
        caption="Status"
        dataType="number"
        [lookup]="{ dataSource: statuses, valueExpr: 'id', displayExpr: 'label' }"
      />
      <oge-column field="amount" caption="Amount" dataType="number" [format]="{ type: 'currency', currency: 'EUR' }" />
      <oge-column field="ordered" caption="Ordered" dataType="date" [format]="{ type: 'date' }" />
    </oge-grid>

    <ol>
      @for (line of log(); track $index) {
        <li>{{ line }}</li>
      }
    </ol>
  `,
})
export class Demo {
  protected readonly statuses = [
    { id: 1, label: 'Open' },
    { id: 2, label: 'Shipped' },
    { id: 3, label: 'Delivered' },
    { id: 4, label: 'Cancelled' },
  ];
  protected readonly orders: Order[] = [
    { id: 1001, customer: 'Acme Corp', city: 'İzmir', status: 2, amount: 1240.5, ordered: new Date(2026, 9, 3) },
    { id: 1002, customer: 'Ege Textiles', city: 'İstanbul', status: 1, amount: 310, ordered: new Date(2026, 9, 11) },
    { id: 1003, customer: 'Fjord Media', city: 'Berlin', status: 4, amount: 980, ordered: new Date(2026, 8, 21) },
  ];

  protected readonly log = signal<string[]>([]);

  protected guard(event: OgeGridAssistantApplyingEvent): void {
    if (event.slices.includes('columns')) {
      event.cancel = !confirm(`Apply "${event.summary}"?`);
    }
  }

  protected event(event: OgeGridAssistantAppliedEvent): string {
    return `${event.prompt} → ${event.slices.join(', ')}`;
  }
}
```
