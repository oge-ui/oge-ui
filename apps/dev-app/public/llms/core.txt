# @oge-ui/core

> Framework-free data engine shared by every package: sort/filter/group/aggregate pipelines, selection and virtualization math, and the OGE UI Pro license check (`ogeSetLicenseKey`). Installed automatically — you rarely import it directly, except to register a Pro license key.

Part of OGE UI v1.1.5.
Docs and live demos: https://www.ogeui.com/license
Whole-suite reference: https://www.ogeui.com/llms-full.txt

```sh
npm i @oge-ui/core
```

## Writing OGE code

Follow these rules and generated code compiles on the first try.

1. **Standalone only.** There are no NgModules and no `Oge*Module` symbols.
   Import the component class and list it in the host component's `imports`
   array: `imports: [OgeGrid, OgeColumn]`.
2. **Signal APIs, never decorators.** Public members are `input()`,
   `input.required()`, `model()` and `output()` — not `@Input()`/`@Output()`.
   Read them as signals in TypeScript (`grid.selectedKeys()`).
3. **Two-way state is `model()`.** Bind with the banana box against a signal:
   `[(selectedKeys)]="keys"`. `ngModel` is supported by the editors in
   `@oge-ui/inputs` for reactive/template forms, but signal binding is the
   idiomatic form.
4. **Modes are string unions, never enums.** Write the literal:
   `selectionMode="multiple"`, `editMode="batch"`, `stylingMode="outlined"`,
   `severity="danger"`. There is no `OgeSelectionMode.Multiple`.
5. **Outputs are past tense with no `on` prefix** — `(rowClick)`,
   `(selectionChanged)`, `(savedChanges)`, `(clicked)`. Never `(onRowClick)`.
6. **`-ing` outputs are cancelable.** Events like `rowInserting`,
   `rowUpdating`, `rowRemoving`, `savingChanges`, `exporting`, the modal's
   `opening`/`closing` and the tab strip's `selectionChanging` carry a mutable
   `cancel: boolean` — set `event.cancel = true` to veto, and the matching
   past-tense event never fires.
7. **App-wide defaults and every user-facing string** come from a provider:
   `provideOgeGridConfig()`, `provideOgeInputsConfig()`,
   `provideOgeButtonsConfig()`, `provideOgeOverlayConfig()`,
   `provideOgeTabsConfig()`, `provideOgeAccordionConfig()`. Each takes a
   `messages` block — that is how localization works; there is no i18n
   dependency. Pass a function instead of an object
   (`provideOgeGridConfig(() => ({ messages: lang() === 'tr' ? TR : {} }))`)
   and the config is live: components re-render their strings when the signals
   it reads change, so the language switches without a reload.
8. **Styling is CSS custom properties**, all prefixed `--oge-`. Never target
   internal class names to change colors or sizing; override the token.
9. **Templates and slots are structural directives on the markup you want**,
   not `<ng-template>` wrappers:
   `<oge-column field="price"><span *ogeCellTemplate="let value">…</span></oge-column>`,
   `<div *ogeModalFooter>…</div>`.

### Theming

```css
:root {
  --oge-accent: #4f46e5;   /* selection, focus, primary actions */
  --oge-radius-lg: 10px;
  --oge-row-height: 32px;  /* grid & tree-list density */
}
```

Token defaults have zero specificity: a plain `:root` rule (or any class)
wins, and tokens cascade into subtrees. Optional stylesheets, imported once,
ship in `@oge-ui/core` (installed with every package; add it directly under
pnpm): `@oge-ui/core/themes/dark.css` (then `class="oge-theme-dark"` or
`data-oge-theme="dark"` on `<html>` or any subtree; `"auto"` follows
`prefers-color-scheme`, `oge-theme-light` marks a light island),
`@oge-ui/core/themes/tailwind.css` and `@oge-ui/core/themes/bootstrap.css`
(bridge `--oge-*` onto an existing design system).

## Common mistakes

Predictable wrong guesses, and what to write instead.

| Wrong | Right |
| --- | --- |
| `<oge-data-grid>` | `<oge-grid>` |
| `[dataSource]="rows"` | `[data]="rows"` |
| `import { OgeGridModule }` | no modules — `imports: [OgeGrid, OgeColumn]` |
| `@Input() foo` on an OGE component | `readonly foo = input<T>()` |
| `(onRowClick)` / `(onSelectionChanged)` | `(rowClick)` / `(selectionChanged)` |
| `selectionMode="[SelectionMode.Multiple]"` | `selectionMode="multiple"` |
| `<oge-grid-column>` | `<oge-column>` |
| `MatDialog` / `DialogService` | `<oge-modal>` or `OgeModalService.open()` |
| `MessageService` / `ToastrService` / `MatSnackBar` | `OgeToastService.show()` (plus `success/info/warning/error`) |
| `<oge-dropdown>` / `<oge-combobox>` | `<oge-select-box>` (`<oge-tag-box>` when multiple) |
| `::ng-deep .oge-grid-row { … }` | override a `--oge-*` token |
| importing a theme to get default styles | not needed — styles ship with the components |

## API reference

### License API

#### Methods

_@oge-ui/core_

| Name | Type | Description |
| --- | --- | --- |
| `ogeSetLicenseKey(key)` | `(key: string) => void` | Registers the OGE UI Pro license key. Call it once before the first Pro component renders — in `main.ts` before bootstrapping, or at the top of the React entry. Calling it again replaces the key and re-evaluates; a valid key removes the corner notice. The key is verified offline and is safe to ship in the bundle. |
| `ogeLicenseStatus(family)` | `(family: OgeCommercialFamily) => Promise<OgeLicenseStatus>` | How the registered key stands for one family on the current host: `licensed`, `development` (no key, development host), `missing`, `invalid`, `expired` (the update window ended before this release) or `not-covered`. |
| `ogeGetLicenseInfo()` | `() => Promise<OgeLicenseInfo \| null>` | The verified payload of the registered key — licensee, seats, families, issue and expiry day — or `null` without a valid key. |
| `ogeCheckLicense(family)` | `(family: OgeCommercialFamily) => void` | What every Pro component calls on start (through its engine’s `ogeCheck<Family>License`). Never throws, never blocks rendering, no-op during server rendering; on a production host without a valid key it logs one console warning per family and pins a single “OGE UI Pro — unlicensed” link to the page corner. |
| `ogeIsLicenseExemptHost(location?)` | `(location?: { hostname: string; protocol: string }) => boolean` | Whether the page counts as development: `localhost`, `127.*`, `*.localhost`, `*.local`, `*.test`, file URLs, StackBlitz and CodeSandbox, jsdom / happy-dom test runs and the OGE UI docs site. Exempt hosts never show the notice. |
| `ogeDecodeLicenseKey(key)` | `(key: string \| null \| undefined) => OgeDecodedLicenseKey \| null` | Parses a key without verifying it (whitespace and line breaks ignored); `null` when it is not a well-formed `OGE1` key. |
| `ogeVerifyLicenseSignature(decoded, publicKey?)` | `(decoded: OgeDecodedLicenseKey, publicKey?: string) => Promise<boolean \| null>` | Checks the Ed25519 signature with Web Crypto. `null` where the runtime cannot verify Ed25519 at all — the library then trusts a well-formed key rather than penalize the browser. |
| `ogeLicenseCoversFamily(info, family)` | `(info: OgeLicenseInfo, family: OgeCommercialFamily) => boolean` | Whether the key covers a family — `families` holds it or `all` (the OGE UI Pro bundle). |
| `ogeLicenseCoversRelease(info, releaseDate)` | `(info: OgeLicenseInfo, releaseDate: string) => boolean` | Whether a release dated `releaseDate` (`YYYY-MM-DD`) falls inside the key’s update window — the perpetual-fallback rule. |
| `ogeBase64UrlToBytes(text)` | `(text: string) => Uint8Array \| null` | base64url decoding used by the key parser; `null` for invalid input. |
| `resetOgeLicenseForTests(publicKey?)` | `(publicKey?: string) => void` | Test seam: forgets the key, the requested families and the notice, and optionally verifies with another public key so specs can sign with a throwaway pair. |

_Engine hooks (commercial families)_

| Name | Type | Description |
| --- | --- | --- |
| `ogeCheckPivotLicense()` | `() => void` | From `@oge-ui/pivot-engine`; called by the Angular and React pivot grid. |
| `ogeCheckGanttLicense()` | `() => void` | From `@oge-ui/gantt-engine`; called by both Gantt components. |
| `ogeCheckSchedulerLicense()` | `() => void` | From `@oge-ui/scheduler-engine`; called by both schedulers. |
| `ogeCheckKanbanLicense()` | `() => void` | From `@oge-ui/kanban-engine`; called by both Kanban boards. |
| `ogeCheckChartsLicense()` | `() => void` | From `@oge-ui/charts-engine`; called by every chart, gauge, map and the sparkline. |
| `ogeCheckBpmnLicense()` | `() => void` | From `@oge-ui/bpmn-engine`; called by both BPMN editors. |

#### Types

| Name | Type | Description |
| --- | --- | --- |
| `OgeLicenseInfo` | `{ id; licensee; seats; families; issued; expires }` | The decoded key payload. `expires` is the last day of the update window: every release dated on or before it stays licensed forever. |
| `OgeLicenseStatus` | `'licensed' \| 'development' \| 'missing' \| 'invalid' \| 'expired' \| 'not-covered'` | Result of `ogeLicenseStatus()`. |
| `OgeCommercialFamily` | `'pivot' \| 'bpmn' \| 'scheduler' \| 'gantt' \| 'kanban' \| 'charts'` | The six families OGE UI Pro covers. |
| `OgeDecodedLicenseKey` | `{ info: OgeLicenseInfo; signed: string; signature: Uint8Array }` | A parsed key before verification. |
| `OGE_LICENSE_PUBLIC_KEY` | `string` | The Ed25519 public key (raw, base64url) that verifies issued keys. |
| `OGE_LICENSE_KEY_PREFIX` | `'OGE1'` | Key format prefix. |
| `OGE_LICENSE_WATERMARK_CLASS` | `'oge-license-watermark'` | CSS class of the corner notice, for apps that look for it in tests. |
| `OGE_RELEASE_VERSION` | `string` | The suite version of this build. |
| `OGE_RELEASE_DATE` | `string` | The release day of this build (`YYYY-MM-DD`), compared with a key’s `expires`. |

## Demos

Each demo below is a complete standalone component — copy one whole and it compiles.

### Angular key

```ts
// main.ts — before bootstrapping
import { bootstrapApplication } from '@angular/platform-browser';
import { ogeSetLicenseKey } from '@oge-ui/core';
import { App } from './app/app';
import { appConfig } from './app/app.config';

ogeSetLicenseKey('OGE1.eyJpZCI6…');

bootstrapApplication(App, appConfig);
```

### Check key

```ts
import { ogeGetLicenseInfo, ogeLicenseStatus } from '@oge-ui/core';

console.log(await ogeLicenseStatus('gantt')); // 'licensed'
console.log(await ogeGetLicenseInfo());       // { licensee, seats, expires, … }
```

### Env key

```ts
// .env.production (Vite) — or an Angular environment file
// VITE_OGE_LICENSE_KEY=OGE1.eyJpZCI6…

ogeSetLicenseKey(import.meta.env.VITE_OGE_LICENSE_KEY ?? '');
```

### React key

```ts
// main.tsx — before the first render
import { createRoot } from 'react-dom/client';
import { ogeSetLicenseKey } from '@oge-ui/core';
import { App } from './App';

ogeSetLicenseKey('OGE1.eyJpZCI6…');

createRoot(document.getElementById('root')!).render(<App />);
```
