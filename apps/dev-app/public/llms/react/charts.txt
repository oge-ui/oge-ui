# @oge-ui/react-charts

> React charts on a dependency-free SVG kernel: sixteen cartesian series types (line/spline/step/area/stacked/bar/range/scatter/bubble/candlestick), pie and doughnut, radar/polar and a range selector — time and log axes, multiple value axes, strip lines, annotations, wheel/drag zoom and pan, crosshair, shared tooltips, an interactive legend, selection, keyboard point inspection and PNG/SVG export — running the same charts engine and stylesheet as the Angular charts package.
>

Part of OGE UI v1.1.1.
Docs and live demos: https://ogeui.com/components/charts
Whole-suite reference: https://ogeui.com/llms-full.txt

```sh
npm i @oge-ui/react-charts
```

## Writing OGE React code

Follow these rules and generated code compiles on the first try.

1. **These are plain React components.** Import the component and render it:
   `import { OgeButton } from '@oge-ui/react-buttons'`. There is no module, no
   provider requirement and no `imports` array — that is the Angular package.
2. **Import the stylesheet once, at your app entry.**
   `import '@oge-ui/react-buttons/styles.css'`. Components ship no inline
   styles; without this import they render unstyled.
3. **Props are plain props, not signals.** Write `text="Save"`,
   `severity="accent"`, `disabled`. Never call them (`text()`), and never use
   `[prop]`/`[(prop)]` binding syntax — that is Angular template syntax.
4. **Modes are string unions, never enums.** Write the literal:
   `severity="danger"`, `stylingMode="outlined"`, `size="sm"`,
   `selectionMode="single"`. There is no `OgeButtonSeverity.Danger`.
5. **Events are `on*` callbacks taking the payload directly** —
   `onClick={(event) => …}`, `onActionDone={(result) => …}`,
   `onSelectionChange={(change) => …}`. Note this is the mirror image of the
   Angular naming rule: there, outputs drop the `on` prefix; here React's
   convention wins, and the payload is the argument rather than an event object.
6. **Two-way state is the controlled/uncontrolled pair.** Pass `selectedKeys`
   plus `onSelectionChange` to control it yourself, or `defaultSelectedKeys`
   to let the component own it. Same for the button's `loading` /
   `onLoadingChange`.
7. **App-wide defaults and every user-facing string** come from a context
   provider: `<OgeButtonsConfigProvider config={{ clickGuardMs: 300,
   messages: { loading: 'Yükleniyor' } }}>`. That is how localization works;
   there is no i18n dependency. Per-instance overrides use the `messages` prop.
8. **Styling is CSS custom properties**, all prefixed `--oge-`, identical to
   the Angular packages — the two render layers share one stylesheet. Never
   target internal class names; override the token.
9. **Slots are props that take nodes**, not children with directives:
   `icon={<SaveIcon />}`. Free `children` render inside the button after the
   label.
10. **Server components:** every component is a client component
    (`'use client'` is already in the package). Import them from a client
    component, or mark your own file `'use client'`.

### Theming

```css
:root {
  --oge-accent: #4f46e5;   /* selection, focus, primary actions */
  --oge-radius-lg: 10px;
}
```

The theme stylesheets are shared with the Angular packages and ship in
`@oge-ui/core` (installed with every package; add it directly under pnpm):
`@oge-ui/core/themes/dark.css` (then `class="oge-theme-dark"` or
`data-oge-theme="dark"` on `<html>` or any subtree; `"auto"` follows
`prefers-color-scheme`), plus the `tailwind.css` and `bootstrap.css`
bridges.

## Common mistakes

Predictable wrong guesses, and what to write instead.

| Wrong | Right |
| --- | --- |
| `import { OgeButton } from '@oge-ui/buttons'` | `from '@oge-ui/react-buttons'` — the unprefixed package is Angular |
| `imports: [OgeButton]` | nothing — just render `<OgeButton />` |
| `[text]="label"` / `[(loading)]="busy"` | `text={label}` / `loading={busy} onLoadingChange={setBusy}` |
| `(clicked)="save()"` | `onClick={save}` |
| `onClick={(e) => e.cancel = true}` | there is no cancelable pre-event on the React buttons |
| `severity={OgeButtonSeverity.Danger}` | `severity="danger"` |
| forgetting the stylesheet | `import '@oge-ui/react-buttons/styles.css'` once at the app entry |
| `<OgeButton icon="save" />` | `icon={<SaveIcon />}` — slots take nodes |
| `::part` / overriding `.oge-button-native` | override a `--oge-*` token |
| rendering it from a server component | mark the file `'use client'` |

## API reference

### <OgeChart>

#### Properties

_Data & series_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `dataSource` | `readonly T[]` | `[]` | Data items; never mutated. |
| `series` | `readonly OgeChartSeriesInput[]` | `[]` | Series definitions: `type` (16 kinds), field mapping (`valueField`/`argumentField` — names, dotted paths or getters), `name`, `color`, `axis` (value-axis index), `stack` group, `dashStyle`/`width`/`opacity`, `showInLegend`, rangeArea bounds (`value1Field`/`value2Field`) and candlestick OHLC (`openField`/`highField`/`lowField`/`closeField`), `sizeField` (bubble area), `visible` (start hidden; the legend re-shows) and `showLabels` (SI-formatted value labels on small series). Null/NaN values render as gaps. Inline arrays are fine: structurally equal props never rebuild the chart. |
| `commonSeries` | `Partial<OgeChartSeriesInput>` | `{}` | Defaults merged under every series (dx `commonSeriesSettings` parity). |
| `palette` | `readonly string[] \| undefined` | `—` | Series colors; defaults to the 10-color `OGE_CHART_PALETTE` (concrete hex values so exported images keep their colors). |

_Axes_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `argumentAxis` | `OgeChartAxisOptions` | `{}` | Argument axis: `type` auto-detects (numbers / dates / categories) when unset; `min`/`max`, `inverted`, `grid`, `title`, `labelFormat`, `labelOverlap` (`rotate`/`skip`/`none`). |
| `valueAxis` | `OgeChartAxisOptions \| readonly OgeChartAxisOptions[]` | `{}` | One or more value axes; series pick theirs via `axis`. `position: 'end'` renders on the right, `type: 'logarithmic'` spaces decades evenly, `abbreviate: false` disables SI labels (`1.2K`). |
| `stripLines` | `readonly OgeChartStripLine[]` | `[]` | Argument-axis markers: `{ start, end?, label?, color? }` — a line without `end`, a shaded band with it. |
| `annotations` | `readonly OgeChartAnnotation[]` | `[]` | Plot annotations: `type: 'point'` draws a marker dot with a connector into a label box at (`argument`, `value`); `'text'` places the label alone (top of the plot without a value). `axis`, `color` and `offsetX/Y` refine placement. |

_Interaction_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `zoomEnabled / panEnabled` | `'none' \| 'wheel' \| 'drag' \| 'both' / boolean` | `'none' / false` | Cursor-centered wheel zoom (a non-passive listener, so the page does not scroll under it), drag-select zoom (Escape cancels mid-drag, 8px threshold), Shift+drag pan. Escape on the focused plot resets the zoom. |
| `visualRange / defaultVisualRange` | `OgeChartRange \| null` | `undefined / null` | The zoom window in argument-axis units (`null` = full extent) — controlled when `visualRange` is provided (pair it with `onVisualRangeChange`), otherwise seeded by `defaultVisualRange`. Writes clamp into the data bounds. |
| `tooltip` | `OgeChartTooltipOptions` | `{}` | `{ enabled?, shared? }` — shared lists every series at the hovered argument; otherwise the value-nearest series wins. |
| `crosshair` | `OgeChartCrosshairOptions` | `{}` | `{ enabled?, horizontal? }` — the vertical tracker snaps to the nearest argument (binary search). |
| `legend` | `OgeChartLegendOptions` | `{}` | `{ visible?, position? (top/bottom/start/end), interactive? }` — real buttons with `aria-pressed`; clicking toggles the series and the axes rescale. |
| `selectionMode / selectedPoints / defaultSelectedPoints` | `'point' \| 'series' \| 'none' / readonly OgeChartPointRef[]` | `'none' / undefined / []` | Click (or Enter) selects; Ctrl adds points to the set; series mode selects the whole series. `selectedPoints` is controlled when provided (pair it with `onSelectedPointsChange`). |

_Appearance & i18n_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `title / subtitle` | `string` | `''` | Headings above the plot. |
| `animation` | `boolean` | `true` | Hover/selection transitions; honors `prefers-reduced-motion`. |
| `locale` | `string \| undefined` | `—` | BCP 47 locale for every `Intl` format; defaults to the config locale, then the browser locale. |
| `messages` | `Partial<OgeChartsMessages>` | `{}` | Per-instance message overrides, merged over the provider config per top-level block. |
| `className / style` | `string / CSSProperties` | `—` | Applied to the `.oge-chart` host element — give it a height (`style={{ height: 380 }}`). |

#### Methods

_OgeChartHandle (ref)_

| Name | Type | Description |
| --- | --- | --- |
| `zoomToRange(range) / resetZoom()` | `void` | Programmatic zoom (clamped into the data bounds) / back to the full extent, announced. |
| `hideTooltip()` | `void` | Clears the hover state (tooltip + crosshair). |
| `refresh()` | `void` | Re-measures the container (ResizeObserver normally covers it). |
| `focus()` | `void` | Focuses the keyboard-inspectable plot region. |
| `getExportData()` | `OgeChartExportData<T>` | Snapshot for custom pipelines: per-series names/types/colors/visibility/points plus the plotted range. |
| `getSvgElement()` | `SVGSVGElement` | The live SVG root — what the image exporters serialize. |

_Export entry point (lazy, dependency-free)_

| Name | Type | Description |
| --- | --- | --- |
| `exportChartToPng(chart, options?) / exportChartToSvg(chart, options?) / serializeChartSvg(svg, options?)` | `@oge-ui/react-charts/export-image` | The same functions as `@oge-ui/charts/export-image` (they live in the shared engine): the live SVG is cloned with computed styles inlined, then downloaded as a standalone `.svg` or rasterized onto a canvas for `.png` (`pixelRatio`, `background`). Pass any chart’s `ref` handle; import the entry point dynamically. |

#### Events

| Name | Type | Description |
| --- | --- | --- |
| `onPointClick / onSeriesClick` | `(event: OgeChartPointEvent<T>) => void / (event: OgeChartSeriesEvent) => void` | Pointer (and keyboard Enter) activation with the normalized point payload. |
| `onLegendClick` | `(event: OgeChartLegendClickEvent) => void` | Cancelable — set `event.cancel = true` to veto the visibility toggle; carries `willHide`. |
| `onTooltipShowing` | `(event: OgeChartTooltipShowingEvent<T>) => void` | Cancelable, before the tooltip shows for a new argument. |
| `onVisualRangeChange / onSelectedPointsChange` | `(range: OgeChartRange \| null) => void / (points: readonly OgeChartPointRef[]) => void` | The controlled halves of `visualRange` / `selectedPoints`; Angular’s `[(…)]` models are both halves at once. |
| `onDrawn` | `() => void` | After every render pass of the series. |

#### Types

| Name | Type | Description |
| --- | --- | --- |
| `OgeChartSeriesType` | `string union` | 'line' \| 'spline' \| 'stepLine' \| 'area' \| 'splineArea' \| 'stepArea' \| 'stackedArea' \| 'fullStackedArea' \| 'bar' \| 'stackedBar' \| 'fullStackedBar' \| 'rangeBar' \| 'scatter' \| 'bubble' \| 'rangeArea' \| 'candlestick'. |
| `OgeChartPoint<T>` | `interface` | The normalized point: `argument`, `argNumeric`, `value`(s incl. OHLC), `source`, `index`. |
| `OgeChartAxisType / OgeChartRange` | `'linear' \| 'logarithmic' \| 'category' \| 'time' / { min, max }` | Axis kinds and the numeric window type (time axes: epoch ms; category: index space). |
| `OgeChartHandle<T>` | `ref handle` | Every method above: `zoomToRange`, `resetZoom`, `hideTooltip`, `refresh`, `focus`, `getExportData`, `getSvgElement`. |

_Template directives (render props)_

| Name | Type | Description |
| --- | --- | --- |
| `renderTooltip` | `(points: readonly OgeChartPointEvent<T>[]) => ReactNode` | Replaces the tooltip's content — the React face of `*ogeChartTooltipTemplate`; one entry per series in shared mode. |
| `renderAnnotation` | `(note: { text: string }) => ReactNode` | Replaces an annotation's label (rendered in a `foreignObject`, so any markup works) — `*ogeChartAnnotationTemplate`. |
| `renderLegendItem` | `(item: OgeChartLegendItem) => ReactNode` | Replaces a legend item's content — `*ogeChartLegendTemplate`; the item is `{ name, color, hidden }`. |

### Configuration

#### Properties

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `OgeChartsConfigProvider` | `component ({ config?: OgeChartsConfigInput })` | `—` | Configures every chart below the provider — the React counterpart of `provideOgeChartsConfig()`. Shallow merge over the outer provider (or `OGE_DEFAULT_CHARTS_CONFIG`) per top-level key — a partial `messages` replaces whole nested blocks — and it re-resolves whenever `config` changes, which is how the UI language switches at runtime. |
| `useOgeChartsConfig()` | `OgeChartsConfig` | `—` | The resolved config of the current subtree. |
| `messages` | `OgeChartsMessages` | `—` | Every user-facing string, aria labels included: `aria` (`OgeChartsAriaMessages` — chart/pie labels with `{title}`/`{count}`, table caption, plot hint, legend label), `announcements` (`OgeChartsAnnouncementMessages` — live-region templates with `{series}`/`{argument}`/`{value}`) and `noData`. Defaults: `OGE_DEFAULT_CHARTS_MESSAGES`. |
| `locale` | `string \| undefined` | `—` | BCP 47 locale for every `Intl` format in scope; a per-instance `locale` prop wins. |
| `a11yTableLimit` | `number` | `50` | Rows of the screen-reader data table. |
| `markerThreshold` | `number` | `200` | Marker circles render only up to this many points per series — beyond it the single path carries the series alone. Line-family paths additionally auto-downsample with LTTB to about one point per pixel once a series outgrows the plot width (hit-testing and tooltips keep the full data). |

## Demos

Each demo below is a complete standalone component — copy one whole and it compiles.

### Getting started

```ts
'use client';

import { OgeChart } from '@oge-ui/react-charts';
import type { OgeChartSeriesInput } from '@oge-ui/react-charts';

const data = [
  { quarter: 'Q1', product: 120, services: 60 },
  { quarter: 'Q2', product: 150, services: 74 },
  { quarter: 'Q3', product: 138, services: 90 },
  { quarter: 'Q4', product: 190, services: 105 },
];

const series: OgeChartSeriesInput[] = [
  { type: 'bar', argumentField: 'quarter', valueField: 'product', name: 'Product' },
  { type: 'line', argumentField: 'quarter', valueField: 'services', name: 'Services' },
];

export function QuarterlyRevenue() {
  return (
    // One element, a working chart: category axis auto-detected from the
    // string arguments, nice-tick value axis, interactive legend (click hides a
    // series), hover tooltip and crosshair. Everything is drawn as
    // dependency-free SVG — no D3, no canvas library.
    <OgeChart
      dataSource={data}
      series={series}
      title="Quarterly revenue"
      style={{ height: 380 }}
    />
  );
}
```

### Series types

```ts
'use client';

import { OgeChart } from '@oge-ui/react-charts';
import type { OgeChartSeriesInput } from '@oge-ui/react-charts';

const data = Array.from({ length: 14 }, (_, i) => ({
  day: i + 1,
  smooth: Math.sin(i / 2) * 30 + 60,
  lo: Math.sin(i / 2) * 12 + 22,
  hi: Math.sin(i / 2) * 12 + 42,
  dots: Math.cos(i / 1.5) * 25 + 55,
  weight: (i % 5) + 1,
}));

const series: OgeChartSeriesInput[] = [
  { type: 'rangeBar', value1Field: 'lo', value2Field: 'hi', name: 'Band' },
  { type: 'stepLine', valueField: 'smooth', name: 'Steps', width: 2.5 },
  {
    type: 'bubble',
    valueField: 'dots',
    sizeField: 'weight',
    name: 'Bubbles',
    opacity: 0.75,
  },
];

export function SeriesTypes() {
  return (
    // Sixteen series types share one engine: line/spline/step lines, five
    // area flavors, four bar flavors (incl. rangeBar spanning value1..value2),
    // scatter, bubble (sizeField drives the AREA of each bubble), rangeArea
    // and candlestick. showLabels prints SI-formatted values next to small
    // series; null values become gaps, never fake zeros. Hovering a legend
    // item spotlights its series.
    <OgeChart
      dataSource={data}
      series={series}
      commonSeries={{ argumentField: 'day' }}
      style={{ height: 380 }}
    />
  );
}
```

### Selection, i18n & export

```ts
'use client';

import { useRef, useState } from 'react';
import { OgeChart } from '@oge-ui/react-charts';
import type { OgeChartHandle, OgeChartPointEvent, OgeChartPointRef, OgeChartSeriesInput } from '@oge-ui/react-charts';

const data = [
  { month: 'Jan', value: 12 },
  { month: 'Feb', value: 31 },
  { month: 'Mar', value: 24 },
  { month: 'Apr', value: 42 },
];

const series: OgeChartSeriesInput[] = [
  { type: 'bar', argumentField: 'month', valueField: 'value', name: 'Value' },
];

export function SelectableChart() {
  // App-wide: wrap the tree in
  // <OgeChartsConfigProvider config={{ locale: 'de', a11yTableLimit: 100 }}>
  const chart = useRef<OgeChartHandle>(null);
  const [selected, setSelected] = useState<readonly OgeChartPointRef[]>([]);
  const lastPoint = useRef<OgeChartPointEvent | null>(null);

  /** The exporter loads lazily and needs no third-party library at all. */
  const exportPng = async (): Promise<void> => {
    const { exportChartToPng } = await import('@oge-ui/react-charts/export-image');
    if (chart.current) await exportChartToPng(chart.current, { filename: 'chart.png' });
  };
  const exportSvg = async (): Promise<void> => {
    const { exportChartToSvg } = await import('@oge-ui/react-charts/export-image');
    if (chart.current) exportChartToSvg(chart.current, { filename: 'chart.svg' });
  };
  return (
    <>
      {/* selectionMode="point" rings clicked points (Ctrl adds); onLegendClick
          is cancelable. Every user-facing string, aria included, lives in
          OgeChartsMessages (OgeChartsConfigProvider, locale). The
          dependency-free export entry serializes the SVG with inlined styles —
          PNG via canvas rasterization, or the standalone .svg itself. */}
      <div className="mb-2 flex gap-2">
        <button type="button" onClick={() => void exportPng()}>Export PNG</button>
        <button type="button" onClick={() => void exportSvg()}>Export SVG</button>
      </div>
      <OgeChart
        ref={chart}
        dataSource={data}
        series={series}
        selectionMode="point"
        selectedPoints={selected}
        onSelectedPointsChange={setSelected}
        locale="de"
        onPointClick={(event) => {
          lastPoint.current = event;
        }}
        style={{ height: 340 }}
      />
    </>
  );
}
```

### Time axis & strip lines

```ts
'use client';

import { OgeChart } from '@oge-ui/react-charts';
import type { OgeChartSeriesInput, OgeChartStripLine } from '@oge-ui/react-charts';

const data = Array.from({ length: 120 }, (_, i) => ({
  date: new Date(2026, 0, 1 + i),
  visitors: 400 + Math.sin(i / 9) * 150 + (i % 17) * 8,
}));

const series: OgeChartSeriesInput[] = [
  { type: 'area', argumentField: 'date', valueField: 'visitors', name: 'Visitors' },
];

const stripLines: OgeChartStripLine[] = [
  { start: new Date(2026, 2, 1), end: new Date(2026, 2, 15), label: 'Campaign' },
  { start: new Date(2026, 3, 10), label: 'Release', color: '#dc2626' },
];

export function VisitorsOverTime() {
  return (
    // Date arguments auto-detect the time axis: ticks are calendar-true (real
    // month boundaries, DST-safe) and labels format through Intl in your
    // locale. stripLines mark a deadline (line) or a window (band) on the
    // argument axis.
    <OgeChart
      dataSource={data}
      series={series}
      stripLines={stripLines}
      argumentAxis={{ grid: true }}
      style={{ height: 380 }}
    />
  );
}
```

### Zoom, pan & tooltips

```ts
'use client';

import { useState } from 'react';
import { OgeChart } from '@oge-ui/react-charts';
import type { OgeChartRange, OgeChartSeriesInput } from '@oge-ui/react-charts';

const data = Array.from({ length: 50_000 }, (_, i) => ({
  t: new Date(2026, 0, 1, 0, i * 15),
  cpu: 40 + Math.sin(i / 60) * 25 + (i % 13),
  memory: 55 + Math.cos(i / 90) * 18 + (i % 7),
}));

const series: OgeChartSeriesInput[] = [
  { type: 'line', argumentField: 't', valueField: 'cpu', name: 'CPU' },
  { type: 'line', argumentField: 't', valueField: 'memory', name: 'Memory' },
];

export function ServerLoad() {
  const [range, setRange] = useState<OgeChartRange | null>(null);
  return (
    // 50,000 points per series stay fluid: paths auto-downsample with LTTB
    // (Largest-Triangle-Three-Buckets — peaks survive) to roughly one point per
    // pixel, hit-testing is a binary search over the FULL data and pointer work
    // is rAF-coalesced. Wheel zooms around the cursor, dragging selects a
    // range, Shift+drag pans, Escape resets; visualRange is controlled; shared
    // tooltips list every series.
    <OgeChart
      dataSource={data}
      series={series}
      visualRange={range}
      onVisualRangeChange={setRange}
      zoomEnabled="both"
      panEnabled
      tooltip={{ shared: true }}
      crosshair={{ horizontal: true }}
      style={{ height: 380 }}
    />
  );
```

```ts
'use client';

import { useState } from 'react';
import { OgeChart, OgeRangeSelector } from '@oge-ui/react-charts';

  const [range, setRange] = useState<OgeChartRange | null>(null);
  return (
    <>
      {/* The overview strip: a mini background chart with a draggable window
```
