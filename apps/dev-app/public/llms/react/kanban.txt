# @oge-ui/react-kanban

> React Kanban board: columns + swimlanes over a plain card array with field mapping, WIP limits, per-column virtualization, drag & drop with Escape-cancel and edge auto-scroll, Ctrl+Arrow keyboard card moving with live announcements, cancelable CRUD and move callbacks, built-in edit dialog, context menu and toolbar — running the same engine and stylesheet as the Angular Kanban package.


## Writing OGE React code

Follow these rules and generated code compiles on the first try.

1. **These are plain React components.** Import the component and render it:
   `import { OgeButton } from '@oge-ui/react-buttons'`. There is no module, no
   provider requirement and no `imports` array — that is the Angular package.
2. **Import the stylesheet once, at your app entry.**
   `import '@oge-ui/react-buttons/styles.css'`. Components ship no inline
   styles; without this import they render unstyled.
3. **Props are plain props, not signals.** Write `text="Save"`,
   `severity="accent"`, `disabled`. Never call them (`text()`), and never use
   `[prop]`/`[(prop)]` binding syntax — that is Angular template syntax.
4. **Modes are string unions, never enums.** Write the literal:
   `severity="danger"`, `stylingMode="outlined"`, `size="sm"`,
   `selectionMode="single"`. There is no `OgeButtonSeverity.Danger`.
5. **Events are `on*` callbacks taking the payload directly** —
   `onClick={(event) => …}`, `onActionDone={(result) => …}`,
   `onSelectionChange={(change) => …}`. Note this is the mirror image of the
   Angular naming rule: there, outputs drop the `on` prefix; here React's
   convention wins, and the payload is the argument rather than an event object.
6. **Two-way state is the controlled/uncontrolled pair.** Pass `selectedKeys`
   plus `onSelectionChange` to control it yourself, or `defaultSelectedKeys`
   to let the component own it. Same for the button's `loading` /
   `onLoadingChange`.
7. **App-wide defaults and every user-facing string** come from a context
   provider: `<OgeButtonsConfigProvider config={{ clickGuardMs: 300,
   messages: { loading: 'Yükleniyor' } }}>`. That is how localization works;
   there is no i18n dependency. Per-instance overrides use the `messages` prop.
8. **Styling is CSS custom properties**, all prefixed `--oge-`, identical to
   the Angular packages — the two render layers share one stylesheet. Never
   target internal class names; override the token.
9. **Slots are props that take nodes**, not children with directives:
   `icon={<SaveIcon />}`. Free `children` render inside the button after the
   label.
10. **Server components:** every component is a client component
    (`'use client'` is already in the package). Import them from a client
    component, or mark your own file `'use client'`.

### Theming

```css
:root {
  --oge-accent: #4f46e5;   /* selection, focus, primary actions */
  --oge-radius-lg: 10px;
}
```

The theme stylesheets are shared with the Angular packages and ship in
`@oge-ui/core` (installed with every package; add it directly under pnpm):
`@oge-ui/core/themes/dark.css` (then `class="oge-theme-dark"` or
`data-oge-theme="dark"` on `<html>` or any subtree; `"auto"` follows
`prefers-color-scheme`), plus the `tailwind.css` and `bootstrap.css`
bridges.

## Common mistakes

Predictable wrong guesses, and what to write instead.

| Wrong | Right |
| --- | --- |
| `import { OgeButton } from '@oge-ui/buttons'` | `from '@oge-ui/react-buttons'` — the unprefixed package is Angular |
| `imports: [OgeButton]` | nothing — just render `<OgeButton />` |
| `[text]="label"` / `[(loading)]="busy"` | `text={label}` / `loading={busy} onLoadingChange={setBusy}` |
| `(clicked)="save()"` | `onClick={save}` |
| `onClick={(e) => e.cancel = true}` | there is no cancelable pre-event on the React buttons |
| `severity={OgeButtonSeverity.Danger}` | `severity="danger"` |
| forgetting the stylesheet | `import '@oge-ui/react-buttons/styles.css'` once at the app entry |
| `<OgeButton icon="save" />` | `icon={<SaveIcon />}` — slots take nodes |
| `::part` / overriding `.oge-button-native` | override a `--oge-*` token |
| rendering it from a server component | mark the file `'use client'` |

## API reference

### <OgeKanban>

#### Properties

_Data_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `dataSource` | `readonly T[]` | `[]` | Card items — a plain array, copied into an internal working set; the array is never mutated. A new array re-seeds the board. Edits surface through the past-tense callbacks. |
| `keyExpr / columnExpr / titleExpr / descriptionExpr / colorExpr` | `string \| ((item: T) => unknown)` | `'id' / 'status' / 'title' / 'description' / 'color'` | Card field mapping: names (dotted paths reach nested objects) or getter functions. `columnExpr` holds the card's column key; a card with no resolvable column lands in the untitled column instead of being dropped. |
| `orderExpr` | `string \| ((item: T) => unknown) \| undefined` | `undefined` | Numeric in-column sort order. Unset, the array order is the board order and moves reorder the working set; set, moves write a midpoint order value back onto the item (sequential renumber of the cell when the midpoint has no room). |
| `swimlaneExpr` | `string \| ((item: T) => unknown) \| undefined` | `undefined` | Set = the board renders collapsible swimlane rows (first-seen data order); each lane holds every column. |
| `tagsExpr / assigneeExpr` | `string \| ((item: T) => unknown) \| undefined` | `undefined` | Tag chips and assignee avatars (initials). Both accept a single value _or_ an array — write-back preserves the storage shape. |
| `dueDateExpr / priorityExpr` | `string \| ((item: T) => unknown) \| undefined` | `undefined` | Due-date badge (danger when overdue; formatted through `locale`) and the priority indicator (colored by value: `'low'` green, `'medium'`/`'normal'` amber, `'high'`/`'urgent'`/`'critical'` red). |
| `searchExprs` | `readonly (string \| ((item: T) => unknown))[] \| undefined` | `undefined` | Extra fields the toolbar search matches, beyond the built-in title + description + tags + assignees haystack. Matching is fold-insensitive (accents, Turkish İ/i). |
| `columns` | `readonly OgeKanbanColumn[] \| undefined` | `undefined` | Declared columns (`{ key, title?, color?, wipLimit?, minCount?, collapsed?, allowAdding?, allowDrag?, allowDrop?, transitionColumns? }`); unset = derived from the data's distinct column keys in first-seen order. Cards in undeclared columns stay in the data but leave the view. |

_State (controlled / uncontrolled)_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `collapsedColumns / collapsedSwimlanes` | `readonly string[]` | `uncontrolled, []` | Collapsed column keys (slim vertical pills) and collapsed swimlane keys. Controlled when provided; `defaultCollapsedColumns` / `defaultCollapsedSwimlanes` seed the uncontrolled state at mount. |
| `columnOrder` | `readonly string[]` | `uncontrolled, []` | Persisted column key order (empty = declared order); written by header drags when `allowColumnReordering` is on. `defaultColumnOrder` seeds it uncontrolled. |
| `selectedCardKey` | `unknown` | `uncontrolled, null` | The selected card's key — single selection. `defaultSelectedCardKey` seeds it uncontrolled. |
| `selectedCardKeys` | `readonly unknown[]` | `uncontrolled, []` | Every selected card key, in board order (`defaultSelectedCardKeys` seeds it uncontrolled). Ctrl/⌘-click toggles, Shift-click selects the range in the anchor's column, Ctrl+A on a card selects its column (cell), Ctrl+Space toggles, Shift+↑/↓ extends and Escape collapses to the focused card. Selected cards travel together in a drag (the ghost shows the count), Ctrl+←/→ and Delete. |
| `filterValue` | `OgeKanbanFilterExpression` | `uncontrolled, {}` | The filter chip bar's state — active `tags` / `assignees` / `priorities` (`defaultFilterValue` seeds it uncontrolled); ANDs with `filter` and the toolbar search. |
| `columnSort` | `OgeKanbanColumnSort<T>` | `uncontrolled, {}` | Per-column card sort: a column key (or `'*'`) mapped to `{ field: 'order' \| 'title' \| 'priority' \| 'dueDate', direction? }` or a comparator (`defaultColumnSort` seeds it uncontrolled). The column menu writes it through `onColumnSortChange`; a drop into a sorted column lands where the sort puts it. |
| `onSelectedCardKeysChange / onFilterValueChange / onColumnSortChange` | `(value) => void` | `—` | The controlled halves of the three G3b state props — Angular's `[(…)]` models are both halves at once. |
| `onCollapsedColumnsChange / onCollapsedSwimlanesChange / onColumnOrderChange / onSelectedCardKeyChange` | `(value) => void` | `—` | The controlled halves of the four state props — Angular's `[(…)]` models are both halves at once. |

_Filtering, selection & transfers_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `filter` | `OgeKanbanFilter<T> \| undefined` | `undefined` | Programmatic card filter: a predicate over the normalized card, or an `OgeKanbanFilterExpression` (`{ tags?, assignees?, priorities?, columns?, swimlanes?, text?, overdue? }` — values inside a field are alternatives, fields combine with AND). Filters only what is shown: WIP counts, exports (unless `visibleOnly`) and the chips stay on the full data. |
| `showFilterBar` | `boolean` | `false` | Shows the filter chip bar under the toolbar: one toggle chip (`aria-pressed`) per distinct tag, assignee and priority, plus a reset button. |
| `priorityOrder` | `readonly string[] \| undefined` | `undefined` | Priority ranking for `columnSort` by priority, most important first (case-insensitive). Unset: `urgent, critical, highest, high, medium, normal, low, lowest`; numeric priorities compare as numbers. |
| `selectionMode` | `'single' \| 'multiple'` | `'multiple'` | `'multiple'` adds Ctrl/Shift-click, the selection shortcuts and multi-card drag; `'single'` keeps one selected card. |
| `dragGroup / boardId` | `string \| undefined` | `undefined` | Boards sharing a `dragGroup` exchange cards: drag a card (or a selection) onto the other board, or use the card menu's “Move to …” entries — the keyboard and single-pointer twin. `boardId` names the board in the transfer callbacks and the other boards' menus (a generated id otherwise). |
| `swimlaneWipLimits` | `Readonly<Record<string, number>> \| undefined` | `undefined` | Per-lane total WIP limits keyed by swimlane value — the lane header's count turns danger when exceeded. Per-cell limits are `OgeKanbanColumn.swimlaneWipLimit` (the column inside each lane). |
| `checklistExpr` | `string \| ((item: T) => unknown) \| undefined` | `undefined` | Checklist / sub-task field: an array of `{ text, done }` (`title` / `checked` / `completed` and plain strings are read too). Cards show a progress badge with an ICU-plural screen-reader text; `toggleChecklistItem()` writes back in the entry's own shape. |
| `quickAdd / inlineTitleEditing` | `boolean` | `false / false` | `quickAdd`: the column footer's add button opens an inline title composer (Enter adds and keeps it open, Escape closes) instead of the dialog. `inlineTitleEditing`: double-clicking a card title edits it in place; F2 on a card always does (both through `onCardAdding` / `onCardUpdating`). |
| `undoLimit` | `number` | `50` | Undo/redo depth — Ctrl+Z / Ctrl+Y (or Ctrl+Shift+Z) and the toolbar buttons. Undo replays the inverse through the cancelable pipelines, so the `-ing` / `-ed` events fire as for the original edit; a multi-card move or bulk delete is one step. Cross-board transfers are not recorded (they span two boards). `0` disables history and hides the buttons. |

_Behavior_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `virtualScrolling` | `boolean` | `true` | Per-column card windowing over a fixed `cardHeight` — 10k cards stay smooth. Rich variable-height render props may opt out (`false`), the documented exception. |
| `cardHeight` | `number \| undefined` | `undefined (config: 112)` | Fixed card height in px; also drives the drag hit-testing and the keyboard scroll-into-view math. |
| `showToolbar` | `boolean` | `true` | The built-in toolbar: primary add button, collapse/expand-all pill and the search box. |
| `allowAdding / allowUpdating / allowDeleting / allowDragging / allowColumnReordering / allowColumnAdding` | `boolean` | `true / true / true / true / false / false` | Capability gates for the toolbar, dialog, menu, hover quick actions, keyboard shortcuts and drags. `allowColumnAdding` renders the "+ Add column" ghost column (inline composer → cancelable `onColumnAdding` → `onColumnAdded`). Per-column `allowAdding: false` overrides the board. |
| `columnWidth` | `number` | `300` | Fixed column track width in px — headers stay legible and the board scrolls horizontally, Trello-style. |
| `cardColorMode` | `'stripe' \| 'surface'` | `'stripe'` | How `colorExpr` renders: an accent bar on the card's edge, or the whole card surface tinted with the color. |
| `rtlEnabled` | `boolean \| undefined` | `undefined` | Right-to-left layout: the first column sits on the right, ArrowLeft/Right roving and Ctrl+Arrow card moves are mirrored (ArrowLeft goes to the next column), the column-reorder drag and drop hit-testing follow the mirrored geometry and the collapsed-lane chevron points left. Unset follows the page — the computed `direction` or the nearest `dir` attribute, read after the first render and kept current when a `dir` changes; an explicit value also sets `dir` on the host. |
| `dialogItems` | `readonly OgeFormItemDefinition[] \| undefined` | `undefined` | Replaces the edit dialog's default form wholesale (`<OgeForm>` items from `@oge-ui/react-forms`); `onCardEditDialogShowing` can still adjust per open. The default form only renders editors for fields the board actually maps. |
| `readOnly` | `boolean` | `false` | One switch over every `allow*` capability; the context menu falls back to the browser's native menu. |
| `messages / locale` | `Partial<OgeKanbanMessages> / string \| undefined` | `{} / undefined` | Per-instance overrides of the context config (`<OgeKanbanConfigProvider>`). Every user-facing string, aria labels and live-region templates included, lives in the messages interface; `locale` drives every Intl format. |

_Render props_

| Name | Type | Description |
| --- | --- | --- |
| `renderCard` | `(context: OgeKanbanCardRenderContext<T>) => ReactNode` | Replaces the card body (`{ card, column, swimlane }`, the card with its `source`). Drag, keyboard and ARIA stay on the board — the React face of `*ogeKanbanCardTemplate`. Buttons, links and inputs it renders are real interactive content: Tab reaches them while the card is its column's tab stop, they never start a drag or feed the board's arrow keys, and Escape returns to the card. |
| `renderColumnHeader` | `(context: OgeKanbanColumnHeaderRenderContext) => ReactNode` | Replaces the column header's title row (`{ column, count, wip }`); the add and collapse affordances stay — the React face of `*ogeKanbanColumnHeaderTemplate`. |
| `className / style` | `string / CSSProperties` | Host styling, merged onto the `.oge-kanban` element (give the board a height, as with the Angular host). |

#### Events

_Callbacks_

| Name | Type | Description |
| --- | --- | --- |
| `onCardClick / onCardDblClick / onCardContextMenu` | `(event: OgeKanbanCardEvent<T>) => void` | Pointer interactions with a card (`{ card, event }`, the native `MouseEvent`). ## Demos

Each demo below is a complete standalone component — copy one whole and it compiles.

### Filter chips & search

```ts
'use client';

import { useState } from 'react';
import { OgeKanban } from '@oge-ui/react-kanban';
import type { OgeKanbanFilterExpression } from '@oge-ui/react-kanban';

const columns = [
  { key: 'todo', title: 'To do' },
  { key: 'doing', title: 'In progress', wipLimit: 3 },
  { key: 'done', title: 'Done' },
];

const tasks = [
  { id: 1, status: 'todo', title: 'Checkout revamp', labels: ['feature'], owner: 'Ada Lovelace', priority: 'high' },
  { id: 2, status: 'todo', title: 'Wallet UI polish', labels: ['design'], owner: 'Grace Hopper', priority: 'medium' },
  { id: 3, status: 'doing', title: 'Fix login crash', labels: ['bug'], owner: 'Ada Lovelace', priority: 'high' },
  { id: 4, status: 'doing', title: 'Upgrade CI runners', labels: ['infra'], owner: 'Alan Turing', priority: 'low' },
  { id: 5, status: 'done', title: 'Search relevance', labels: ['feature'], owner: 'Grace Hopper', priority: 'medium' },
];

export function ChipBoard() {
  const [chips, setChips] = useState<OgeKanbanFilterExpression>({
    priorities: ['high'],
  });
  const active = [
    ...(chips.tags ?? []),
    ...(chips.assignees ?? []),
```

```ts
'use client';

import { useState } from 'react';
import { OgeKanban } from '@oge-ui/react-kanban';
import type { OgeKanbanCardTransferredEvent } from '@oge-ui/react-kanban';

interface Task {
  id: number;
  status: string;
  title: string;
}

export function PlanningBoards() {
  const [backlog, setBacklog] = useState<Task[]>([
    { id: 1, status: 'todo', title: 'Dark mode' },
    { id: 2, status: 'todo', title: 'CSV import' },
    { id: 3, status: 'todo', title: 'Audit log' },
  ]);
  const [sprint, setSprint] = useState<Task[]>([
    { id: 10, status: 'todo', title: 'Login rate limits' },
  ]);
  // both boards report the transfer — idempotent updates make that harmless
  const onTransferred = (event: OgeKanbanCardTransferredEvent<Task>) => {
    const moved = new Set(event.sourceCards.map((task) => task.id));
    const [setFrom, setTo] =
      event.fromBoard === 'Backlog' ? [setBacklog, setSprint] : [setSprint, setBacklog];
    setFrom((list) => list.filter((task) => !moved.has(task.id)));
    setTo((list) => [...list.filter((task) => !moved.has(task.id)), ...event.cards]);
  };
  return (
    <div style={{ display: 'grid', gap: 12, gridTemplateColumns: '1fr 1fr' }}>
      {/* Boards sharing a dragGroup exchange cards by drag or the card menu's
          "Move to …" entry (the keyboard twin). The target calls the cancelable
          onCardTransferring; both boards call onCardTransferred. */}
      <OgeKanban
        dataSource={backlog}
        keyExpr="id"
        columnExpr="status"
        titleExpr="title"
        dragGroup="planning"
        boardId="Backlog"
        columns={[{ key: 'todo', title: 'Ideas' }]}
        onCardTransferred={onTransferred}
        style={{ height: 360 }}
      />
      <OgeKanban
        dataSource={sprint}
        keyExpr="id"
        columnExpr="status"
        titleExpr="title"
        dragGroup="planning"
        boardId="Sprint"
        columns={[{ key: 'todo', title: 'To do' }, { key: 'doing', title: 'In progress' }]}
```
