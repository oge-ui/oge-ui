# @oge-ui/react-grid

> React data grid: data-driven columns with render props, multi-column sorting, a typed filter row with an operator menu, global search, paging, row and column virtualization, windowed remote loading, single/multiple/checkbox selection, Excel-like keyboard navigation, grouping with summaries and deferred groups, master-detail, row render props, row drag, pinned/resizable/reorderable columns, state persistence and CSV export — running the same framework-free grid engine, state slices and stylesheet as the Angular grid package.

Part of OGE UI v1.1.3.
Docs and live demos: https://www.ogeui.com/components/data-grid
Whole-suite reference: https://www.ogeui.com/llms-full.txt

```sh
npm i @oge-ui/react-grid
```

## Writing OGE React code

Follow these rules and generated code compiles on the first try.

1. **These are plain React components.** Import the component and render it:
   `import { OgeButton } from '@oge-ui/react-buttons'`. There is no module, no
   provider requirement and no `imports` array — that is the Angular package.
2. **Import the stylesheet once, at your app entry.**
   `import '@oge-ui/react-buttons/styles.css'`. Components ship no inline
   styles; without this import they render unstyled.
3. **Props are plain props, not signals.** Write `text="Save"`,
   `severity="accent"`, `disabled`. Never call them (`text()`), and never use
   `[prop]`/`[(prop)]` binding syntax — that is Angular template syntax.
4. **Modes are string unions, never enums.** Write the literal:
   `severity="danger"`, `stylingMode="outlined"`, `size="sm"`,
   `selectionMode="single"`. There is no `OgeButtonSeverity.Danger`.
5. **Events are `on*` callbacks taking the payload directly** —
   `onClick={(event) => …}`, `onActionDone={(result) => …}`,
   `onSelectionChange={(change) => …}`. Note this is the mirror image of the
   Angular naming rule: there, outputs drop the `on` prefix; here React's
   convention wins, and the payload is the argument rather than an event object.
6. **Two-way state is the controlled/uncontrolled pair.** Pass `selectedKeys`
   plus `onSelectionChange` to control it yourself, or `defaultSelectedKeys`
   to let the component own it. Same for the button's `loading` /
   `onLoadingChange`.
7. **App-wide defaults and every user-facing string** come from a context
   provider: `<OgeButtonsConfigProvider config={{ clickGuardMs: 300,
   messages: { loading: 'Yükleniyor' } }}>`. That is how localization works;
   there is no i18n dependency. Per-instance overrides use the `messages` prop.
8. **Styling is CSS custom properties**, all prefixed `--oge-`, identical to
   the Angular packages — the two render layers share one stylesheet. Never
   target internal class names; override the token.
9. **Slots are props that take nodes**, not children with directives:
   `icon={<SaveIcon />}`. Free `children` render inside the button after the
   label.
10. **Server components:** every component is a client component
    (`'use client'` is already in the package). Import them from a client
    component, or mark your own file `'use client'`.

### Theming

```css
:root {
  --oge-accent: #4f46e5;   /* selection, focus, primary actions */
  --oge-radius-lg: 10px;
}
```

The theme stylesheets are shared with the Angular packages and ship in
`@oge-ui/core` (installed with every package; add it directly under pnpm):
`@oge-ui/core/themes/dark.css` (then `class="oge-theme-dark"` or
`data-oge-theme="dark"` on `<html>` or any subtree; `"auto"` follows
`prefers-color-scheme`), plus the `tailwind.css` and `bootstrap.css`
bridges.

## Common mistakes

Predictable wrong guesses, and what to write instead.

| Wrong | Right |
| --- | --- |
| `import { OgeButton } from '@oge-ui/buttons'` | `from '@oge-ui/react-buttons'` — the unprefixed package is Angular |
| `imports: [OgeButton]` | nothing — just render `<OgeButton />` |
| `[text]="label"` / `[(loading)]="busy"` | `text={label}` / `loading={busy} onLoadingChange={setBusy}` |
| `(clicked)="save()"` | `onClick={save}` |
| `onClick={(e) => e.cancel = true}` | there is no cancelable pre-event on the React buttons |
| `severity={OgeButtonSeverity.Danger}` | `severity="danger"` |
| forgetting the stylesheet | `import '@oge-ui/react-buttons/styles.css'` once at the app entry |
| `<OgeButton icon="save" />` | `icon={<SaveIcon />}` — slots take nodes |
| `::part` / overriding `.oge-button-native` | override a `--oge-*` token |
| rendering it from a server component | mark the file `'use client'` |

## API reference

### <OgeGrid>

#### Properties

_Data & columns_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `readonly T[] \| DataSource<T>` | `[]` | Rows to render: a static array or any `DataSource` implementation (remote, windowed, pushing live changes). An array (or a source with `loadSync`) loads in the first render, so `renderToString` already contains the first page; asynchronous sources load after mount. |
| `columns` | `readonly (string \| OgeColumnDef \| OgeGridColumnProps<T>)[]` | `undefined` | The columns. When omitted, columns are derived from the first row’s keys; a plain string is shorthand for `{ field }`. |
| `keyField` | `keyof T \| ((row: T) => RowKey)` | `undefined` | Field (or selector) producing a stable row key; falls back to the row index. |

_Sorting, filtering & search_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `sortable` | `boolean \| 'single' \| 'multi'` | `'multi'` | `false` disables sorting entirely; `'single'` restricts to one column (no shift+click chains). |
| `sorting` | `OgeSortingOptions` | `undefined` | Sorting options (`mode`, `allowUnsorting`); overrides the `sortable` shorthand. |
| `filterRow` | `boolean \| OgeFilterRowOptions` | `false` | Per-column filter editors below the header — text, number, date, boolean and lookup editors with a per-column operator menu. |
| `headerFilter` | `boolean \| OgeHeaderFilterOptions` | `false` | Excel-style distinct-value filter button in the headers. Needs a DataSource that implements `distinct()`; date columns list their values grouped by year. |
| `filterPanel` | `boolean` | `false` | Filter summary bar above the grid; clicking it opens the visual filter builder (arbitrary and/or condition trees). |
| `filterValue / defaultFilterValue` | `FilterExpr \| null` | `null` | The filter-builder expression — controlled with `onFilterValueChange`. Combines with the filter row, the header filters and the search panel. |
| `searchPanel` | `boolean \| OgeSearchPanelOptions` | `false` | Global search box above the grid. |
| `filterDebounce` | `number` | `config.filterDebounce (300)` | Debounce for text filter inputs, in ms. Set to `0` in tests. |
| `announcements` | `boolean` | `config.announcements (true)` | Speaks sort, filter/search result count (debounced, once the new result arrived), page, group expansion, select-all and blocked-save validation changes through the shared `useOgeLiveAnnouncer` regions — texts from the `*Announcement` messages. `false` opts out. |

_Paging & scrolling_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `paging` | `false \| OgePagingOptions` | `false` | Enables paging with the pager: `pageSize`, optional `pageSizes`, `showInfo` and `displayMode`. |
| `virtualScroll` | `boolean` | `false` | Renders only the rows inside the scroll viewport (plus overscan). Give the grid a bounded height when enabled. |
| `scrolling` | `OgeScrollingOptions` | `undefined` | `mode` (`'virtual'` / `'infinite'`), `remote` windowed block loading and `columnRenderingMode: 'virtual'`; overrides the `virtualScroll` shorthand. |
| `rowHeight` | `number` | `config.rowHeight (36)` | Fixed row height in px used by the virtualizer. |
| `autoRowHeight` | `boolean` | `false` | Measures real row heights (wrapped text, render props) instead of forcing `rowHeight`, with scroll anchoring. Virtual mode only. |
| `overscan` | `number` | `config.overscan (6)` | Extra rows rendered above/below the virtual window. |
| `detailRowHeight` | `number` | `config.detailRowHeight (200)` | Height assumed for expanded master-detail rows in virtual mode. |

_Grouping_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `groupPanel` | `boolean` | `false` | Shows the drop area for drag-and-drop row grouping; each group renders as a removable chip. Keyboard: the header context menu (Shift+F10) offers `groupByColumn` / `ungroupColumn`; on a chip’s remove button Ctrl+←/→ reorders the grouping and Delete removes it (`messages.groupMoved` / `groupRemoved`). |
| `groupBy` | `readonly string[]` | `undefined` | Initial/programmatic grouping by field names (also drivable via the group panel). |
| `grouping` | `OgeGroupingOptions` | `undefined` | `autoExpandAll: false` starts every group collapsed and enables deferred loading (`items: null` payloads fetched on expand); `contextMenuEnabled: true` offers group/ungroup in the header menu without the group panel. |

_Selection & focus_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `selectionMode` | `'none' \| 'single' \| 'multiple' \| 'checkbox' \| 'cell'` | `'none'` | Row selection: single, multiple (ctrl/shift ranges, Ctrl+A) or a checkbox column with a select-all header — or `'cell'`: rectangular cell ranges with TSV copy / paste and the fill handle (editing then starts on double-click, F2 or Enter). |

| `selectionDeferred` | `boolean` | `false` | Deferred selection: the selection is an expression rather than a key set, so "select all" over a remote source never materializes keys. Requires a string `keyField`. |
| `selectionFilter` | `FilterExpr \| null` | `null` | The selection expression (deferred mode) — controlled with `onSelectionFilterChange`. |
| `selectAllMode` | `'allPages' \| 'page'` | `'allPages'` | Header select-all scope: the whole filtered set across pages, or only the rows on the current page. |
| `focusedRowEnabled` | `boolean` | `false` | Highlights and tracks a single focused row. |
| `focusedRowKey` | `RowKey \| null` | `undefined` | The focused row’s key — controlled when provided, with `onFocusedRowKeyChange`. |

_Columns UX_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `columnMinWidth` | `number` | `config.columnMinWidth (120)` | Track minimum for columns without an explicit width. |
| `columnHidingMode` | `'hide' \| 'detail' \| undefined` | `config: 'detail'` | What happens to columns responsive hiding (`hidingPriority`) takes out on a narrow grid: `'detail'` gives every row a toggle (a real button with `aria-expanded` / `aria-controls`, labelled by `toggleAdaptiveDetail`) that reveals the hidden columns' caption / value pairs on a second line of the row, rendered like the cells — format, lookups, boolean words and `renderCell`; `'hide'` drops them with no way back. The hiding pass counts the toggle's 32px track once a column is hidden. |
| `columnResize` | `boolean` | `true` | Enables drag-resize handles on header edges. Keyboard: Alt+←/→ on a focused header resizes by 10px (Shift for 1px); the handle is a focusable `role="separator"` (`aria-valuenow/min/max` = width in px, named by `messages.resizeColumn`) taking ←/→, Home/End (min / max) and Enter/Esc (back to the header). RTL-aware; clamped to `minWidth` / `maxWidth`. |
| `columnReorder` | `boolean` | `true` | Enables drag-and-drop column reordering (headers dropped onto each other). Keyboard: Ctrl+Shift+←/→ on a focused header moves the column one step, never across a pinned group or out of its band (an unbanded column steps over a band as a whole), announced via `messages.columnMoved`. |
| `columnChooser` | `boolean` | `false` | Toolbar button opening the show/hide column list; with `columnReorder` its rows also drag to reorder. Keyboard: Space toggles an item; with `columnReorder`, Ctrl+↑/↓ moves it. Hiding is also in the header context menu. |
| `toolbarBefore / toolbarCenter / toolbarAfter` | `ReactNode` | `undefined` | Your own toolbar content by group — the React form of Angular’s `[ogeToolbar]` placement: `toolbarBefore` at the start edge ahead of the group panel (filters, primary actions), `toolbarCenter` in the middle, `toolbarAfter` ahead of the built-in tools. Any of them makes the toolbar render. |

_Editing & rows_

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `editing` | `false \| OgeEditingOptions` | `false` | Enables editing: `{ mode: 'cell' \| 'row' \| 'batch' \| 'popup' \| 'form', allowUpdating, allowAdding, allowDeleting, confirmDelete, formItems, formColCount }`. `form` replaces the row with an inline `<OgeForm>`; `popup` opens the same form in a modal. An invalid cell editor sets `aria-invalid` on its control and points `aria-errormessage` / `aria-describedby` at a rendered, visually hidden error text (also the cell’s tooltip); the `form`/`popup` fields wire the same through `<OgeForm>`. |
| `commandButtons` | `readonly OgeCommandButton<T>[]` | `undefined` | Customizes the trailing command column: reorder or mix the built-in `'edit'` / `'delete'` buttons with your own. Omitted, the column shows the built-ins the `editing` permissions allow. |
| `highlightChanges` | `boolean` | `false` | Briefly flashes cells whose value changed under a live-updating source; consecutive updates to one cell restart the animation. |
| `rowDragging` | `boolean` | `false` | Drag-handle column for reordering rows. With plain-array data the array is mutated in place; DataSource consumers handle `onRowReordered` instead. Keyboard: Ctrl+↑/↓ on a focused cell moves the row onto its neighbour through the same drop path (same event), announced via `messages.rowMoved`. |
| `renderRow` | `(context: OgeGridRowRenderContext<T>) => ReactNode` | `undefined` | Replaces the whole data row — the React form of `*ogeRowTemplate`. Group, detail and summary rows keep their built-in rendering. |
| `renderDetail` | `(context: OgeGridDetailRenderContext<T>) => ReactNode` | `undefined` | Master-detail content under an expanded row — the React form of `*ogeDetailTemplate`. Its presence adds the expander column and switches the role to `treegrid`. |

| `goToPage(page: number)` | `void` | Goes to a 1-based page: its page button when listed, otherwise the go-to-page input. |
| `nextPage() / previousPage()` | `void` | Clicks the pager’s next / previous page button. |

_Selection_

| Name | Type | Description |
| --- | --- | --- |
| `toggleRowSelection(rowIndex: number)` | `void` | Toggles a row’s selection: its checkbox in `selectionMode="checkbox"`, otherwise a click on its first data cell. |
| `isRowSelected(rowIndex: number)` | `boolean` | Whether a row is selected (`aria-selected="true"`). |
| `getSelectedRowIndexes()` | `number[]` | 0-based indexes of the selected rendered rows. |
| `toggleSelectAll()` | `void` | Clicks the header’s select-all checkbox. |

_Editing_

| Name | Type | Description |
| --- | --- | --- |
| `editCell(rowIndex: number, column: string \| number, text: string)` | `void` | Edits a cell as a keyboard user does: focus, F2 (unless already editing), replace the text, Enter — which commits per the edit mode. Text, number and date editors. |
| `isCellEditing(rowIndex: number, column: string \| number)` | `boolean` | Whether a cell shows its editor. |

| --- | --- | --- |
| `OgeGridQueries` | `interface` | What `getGrid()` returns — the members above. |

```ts
'use client';

import { OgeGrid } from '@oge-ui/react-grid';
import type { FilterExpr } from '@oge-ui/core';

interface Employee {
  id: number;
  firstName: string;
  lastName: string;
  department: string;
  city: string;
  salary: number;
}

declare const employees: Employee[];

const departments = [
  { code: 'Engineering', label: 'Mühendislik' },
  { code: 'Sales', label: 'Satış' },
  { code: 'HR', label: 'İnsan Kaynakları' },
  { code: 'Finance', label: 'Finans' },
  { code: 'Support', label: 'Destek' },
];

// sort the lookup column by its display label, not the stored code
const departmentLabel = (row: Employee) =>
  departments.find((d) => d.code === row.department)?.label ?? row.department;

// '60' in the filter row means the 60k band: 60000 <= salary < 61000
const salaryBandFilter = (value: unknown): FilterExpr | null => {
  const band = Number(value);
  if (value == null || value === '' || Number.isNaN(band)) return null;
  return {
    type: 'and',
    operands: [
      { type: 'binary', field: 'salary', op: 'ge', value: band * 1000 },
      { type: 'binary', field: 'salary', op: 'lt', value: (band + 1) * 1000 },
    ],
  };
};

const columns = [
  { field: 'firstName', caption: 'First Name' },
  { field: 'department', caption: 'Department',
    lookup: { dataSource: departments, valueExpr: 'code', displayExpr: 'label' },
    calculateSortValue: departmentLabel },
  { field: 'salary', caption: 'Salary Band (k)', dataType: 'number' as const,
    format: (v: unknown) => `${Math.floor(Number(v) / 1000)}k`,
    calculateFilterExpression: salaryBandFilter },
];

export function CalculatedColumns() {
  return (
    <OgeGrid
      data={employees}
      keyField="id"
      columns={columns}
      filterRow
      paging={{ pageSize: 8 }}
    />
  );
}
```

```ts
  { field: 'city', caption: 'City' },
```
```ts
  { field: 'salary', caption: 'Salary', dataType: 'number' as const },
```

```ts
export function DeferredGroups() {
  // Fake deferred server: group headers only (items: null + count);
  // a group's rows are fetched the moment it is expanded, filtered by the
  // group value, and cached for later toggles.
  const source = useMemo(
    () =>
      new CustomDataSource<Employee>({
        key: 'id',
        load: async (options) => {
          await new Promise((resolve) => setTimeout(resolve, 300));
          if (options.group?.length) {
            const counts = new Map<string, number>();
            for (const row of employees) counts.set(row.department, (counts.get(row.department) ?? 0) + 1);
            return {
              data: [...counts.entries()].sort(([a], [b]) => a.localeCompare(b)).map(([key, count]) => ({ key, items: null, count })),
              totalCount: employees.length,
            };
          }
          const filter = options.filter;
          const value = filter?.type === 'binary' ? filter.value : undefined;
          return { data: employees.filter((row) => row.department === value) };
        },
      }),
    [],
  );
  return (
    <OgeGrid
      data={source}
      columns={columns}
      groupBy={['department']}
      grouping={{ autoExpandAll: false }}
    />
  );
```

```ts
  { field: 'symbol', caption: 'Symbol', width: 100 },

    field: 'change',
    caption: 'Change',
    dataType: 'number',
    // renderCell is the React form of *ogeCellTemplate — and the row is typed
    renderCell: ({ value, row }) => (
      <span className={row.change >= 0 ? 'text-emerald-800' : 'text-red-800'}>
        {String(value)} ({row.changePercent}%)
      </span>
    ),
  },
];

export function Ticker() {
  const stocks = useMemo(() => new ArrayDataSource(SEED_STOCKS, { key: 'id' }), []);

  useEffect(() => {
    // any push source works: WebSocket, SSE, SignalR…
    const timer = setInterval(() => {
      const stock = SEED_STOCKS[Math.floor(Math.random() * SEED_STOCKS.length)];
      const change = Number((Math.random() * 2 - 1).toFixed(2));
      stocks.push([
        {
          type: 'update',
          key: stock.id,
          patch: {
            price: stock.price + change,
            change,
            changePercent: Number(((change / stock.price) * 100).toFixed(2)),
          },
        },
      ]);
    }, 600);
    return () => clearInterval(timer);
  }, [stocks]);
  return (
    // pure updates patch rows in place — no reload, no scroll jump;
    // highlightChanges flashes every patched cell
    <OgeGrid data={stocks} keyField="id" columns={columns} highlightChanges />
  );
}
```

### Drag rows between grids

```ts
'use client';

import { useState } from 'react';
import { OgeGrid } from '@oge-ui/react-grid';
import type { OgeRowDropEvent } from '@oge-ui/react-grid';

interface Task {
  id: number;
  title: string;
}

export function TaskBoards() {
  const [todo, setTodo] = useState<Task[]>([
    { id: 1, title: 'Write specs' },
    { id: 2, title: 'Ship it' },
  ]);
  const [done, setDone] = useState<Task[]>([{ id: 3, title: 'Plan' }]);

  const onDrop = (event: OgeRowDropEvent) => {
    if (event.sameComponent) return; // a reorder: the grid already moved it
    const row = event.sourceRow as Task;
    const [setFrom, setTo] =
      event.targetComponentId === 'todo' ? [setDone, setTodo] : [setTodo, setDone];
    setFrom((rows) => rows.filter((r) => r.id !== row.id));
    setTo((rows) => {
      const next = [...rows];
      next.splice(event.toIndex, 0, row);
      return next;
    });
  };
  return (
    <>
      <OgeGrid id="todo" data={todo} keyField="id" rowDragging rowDragGroup="tasks"
               columns={[{ field: 'title', caption: 'To do' }]} onRowDrop={onDrop} />
      <OgeGrid id="done" data={done} keyField="id" rowDragging rowDragGroup="tasks"
               columns={[{ field: 'title', caption: 'Done' }]} onRowDrop={onDrop} />
    </>
  );
}
```

```ts
            text: 'Select this row only',
```
