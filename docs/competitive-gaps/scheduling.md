# Scheduling family — competitive feature-gap report (Scheduler / Gantt / Kanban)

Date: 2026-10-03. Read-only research. Sources: `apps/dev-app/src/app/pages/{scheduler,gantt,kanban,react-*}/*-api-data.ts`,
`ROADMAP.md` (Scheduler / Gantt / Kanban parity tables), engine sources under
`packages/{scheduler,gantt,kanban}-engine/src/lib` + `packages/{scheduler,gantt,kanban}/src` + `packages/react/{scheduler,gantt,kanban}/src`.
Competitor features from vendor docs/product pages (DevExtreme dxScheduler config reference, Syncfusion Angular Scheduler & Gantt product pages,
Bryntum Scheduler Pro & TaskBoard product pages) plus prior knowledge of Kendo, DHTMLX, Mobiscroll, FullCalendar Premium, Bryntum Gantt.

**React parity:** all three families run one shared core (`OgeSchedulerCore` / `OgeGanttCore` / kanban engine) in both layers;
`tools/docs-tools/check-parity.mjs` records only template↔render-prop and provider↔context differences. Every gap below therefore
applies equally to the Angular and React twins (fix once in the engine, wire twice).

Abbreviations: dx = DevExtreme, K = Kendo UI for Angular, SF = Syncfusion, Bry = Bryntum, DH = DHTMLX, MS = Mobiscroll, FC = FullCalendar Premium.
Verification: "Missing" claims were grepped across `packages/` (engine + Angular + React) — keywords listed in the Notes column where relevant.

## 1. Scheduler (`@oge-ui/scheduler` + `@oge-ui/scheduler-engine`)

### What we have (baseline)

Views `day | week | workWeek | month | agenda | timelineDay | timelineWeek | year`; per-view hour window/cellDuration overrides; all-day panel with lane packing;
overlap layout (equal-width clusters); `maxAppointmentsPerCell` + "+N more" (drills to day); current-time indicator + past shading; `workHours {start,end,days}`;
`weekendDays` (locale-aware via `Intl.Locale#getWeekInfo`), `hiddenWeekDays`, `firstDayOfWeek`; `min/max`; date-navigator calendar; drag-move/resize/create with
snap + Escape; keyboard move/resize (OGE extra); cancelable CRUD pipelines + programmatic CRUD; built-in context menu (OGE extra); popup + `oge-form` editor with
`editorShowing` form hook; recurrence engine (RFC 5545 subset: DAILY..YEARLY, INTERVAL, COUNT/UNTIL, BYDAY±ordinal, BYMONTHDAY, BYMONTH, BYHOUR, BYMINUTE,
BYSETPOS, WKST, UTC `Z`, DTSTART/RDATE/EXDATE blocks) + occurrence/series scope + EXDATE detach; resources (select fields, color-by-resource) + `groups`
(first entry only: timeline rows, day/week sub-columns, drag reassigns); reminders (OGE extra); appointment/cell/date-header templates; `disabledExpr`
per appointment; `readOnly`; full messages/i18n + live-region announcements; columnheader semantics.

## Top 15 gaps for this family (prioritized)

1. **Scheduler time zones** (display TZ + per-appointment TZ fields; Intl offset math, no tz db) — every paid rival has it; blocker for global SaaS buyers. H/L.
2. **Scheduler remote range loading** (load visible period via DataSource LoadOptions) — required for real calendars with years of data. H/M.
3. **Gantt dependency lag/lead** — tiny model change in `schedule.ts` + dialog field; table-stakes vs SF/Bry/DH. H/S.
4. **Gantt task constraints + deadlines + manual/auto task mode** (and backward pass that pulls tasks earlier). H/M–L.
5. **Gantt inline cell editing + sorting + filtering + column resize** in the task list (reuse tree-list/grid editing) — biggest UX gap vs SF/K. H/M.
6. **Scheduler timeline month/year/workWeek views + `intervalCount`** — resource-planning use cases (FC Premium/Bry core). H/M.
7. **Scheduler virtual scrolling for resources/timeline** — needed once timelines exist at scale. H/L.
8. **Scheduler multi-level grouping + orientation + groupByDate** — currently only first `groups` entry. H/M.
9. **Scheduler external drag-in/out** (from grid/kanban/list) — ROADMAP v0.2; common booking workflow. H/M.
10. **Scheduler blocked time ranges + per-resource work hours + overlap prevention/conflict detection** — booking/clinic apps. H/M.
11. **Recurrence editor UI parity with engine** (monthly nth weekday, yearly, BYSETPOS, last day). H/M.
12. **Scheduler adaptive/mobile + touch long-press drag** (also Kanban touch). H/M. — **Partial (W3)**: `adaptiveView` agenda fallback and long-press touch drags in all three; compact mobile header still open.
13. **Scheduler export/print: PDF, Excel, iCal import/export** — reuse gantt lazy exporters. M/M.
