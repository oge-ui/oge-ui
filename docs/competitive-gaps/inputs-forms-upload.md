# OGE editors: competitive feature-gap report (inputs / forms / upload)

Date: 2026-10-03. Read-only research, no changes made to the repo.

**Status refresh (2026-10-04, `main` @ bd6b08e).** Rows closed since the report by wave 3 (adaptive popups), G4a (masks, date segments, time and range depth, number typing, colour and choice editors) and G4b (remote list paging, TagBox parity, SelectBox templates, MultiColumnComboBox, TreeSelect chips, form server errors / conditional items / `compare`) now read **Have** / **Partial** with the shipping wave in brackets. The "zero hits" list below records the original baseline; most of those terms now exist.

**Sources for OGE.** The `apps/dev-app/src/app/pages/{inputs,forms,upload}/*-api-data.ts` member lists, with their React twins (`react-*-api-data.ts`), plus ROADMAP.md (Date editors / Inputs / Toggle / Select family / Tree Select sections). I checked the claims against `packages/inputs/*/src`, `packages/forms/src`, `packages/upload/src` and `packages/behavior/src/lib/{forms,upload}`.

**Sources for competitors.** Official docs feature sets as of my knowledge (DevExtreme 25.x, Kendo UI for Angular 19/20, Syncfusion Angular 2025, PrimeNG 19/20, MUI X v7/v8 Pro). I did no live web fetch. Rows I couldn't confirm in the competitors' docs are marked "(unverified)".

**React twins.** `packages/react/inputs|forms|upload` mirror the Angular member lists. `docs-tools:parity` enforces this, and its only recorded exceptions are Angular-forms specifics (`reset` on a bound control, the `formGroup` binding, and the DI provider ↔ context provider pair). So every gap below applies to both layers unless I note otherwise.

**Legend.** dx = DevExtreme, K = Kendo, SF = Syncfusion, P = PrimeNG, MUI = MUI X Pro. Impact and Effort are each H/M/L (Effort uses S/M/L).

**How I verified "Missing".** For each one I ran a case-insensitive grep over `packages/{inputs,forms,upload,behavior,react}` `*.ts`, excluding specs. These terms had **zero hits**: mask, otp/one-time-code, rating, signature, richtext/contenteditable, mention, knob, timezone/timeZone, adaptive/bottom-sheet, tagTemplate, multiline, selectAll, wheel, hour12/hourCycle, showNowButton, strength, keyFilter, validationGroup, setErrors/serverErrors, multi-column, speech, cascade-select, phone. Separately, `listbox` hits only the internal `role="listbox"` in popups, and `crop` hits only the word "microphone".
