# Competitive feature-gap report: Grid family (Data Grid, Tree List, Pivot Grid, Filter Builder, Pager)

Date: 2026-10-03. Read-only research. Repo state: `main` @ 0092025.

Legend: **DX** = DevExtreme (DataGrid/TreeList/PivotGrid), **K** = Kendo UI for Angular, **SF** = Syncfusion Angular,
**AG** = AG Grid Enterprise, **MUI** = MUI X Data Grid Pro/Premium. Impact: H/M/L. Effort: S (≤3 days), M (1–2 weeks), L (3+ weeks).
OGE status: **Have** / **Partial** (with what is missing) / **Missing** / **Unverified**.

## 0. How the OGE baseline was established

- `ROADMAP.md` (grid/tree-list/pivot parity tables, Phases 10–18), `docs/REACT-PARITY.md` (React grid, tree-list and pivot are at full parity).
- API data: `apps/dev-app/src/app/pages/{data-grid,tree-list,pivot-grid,react-grid,react-tree-list,react-pivot}/*-api-data.ts`.
- Code checks (grep across `packages/{grid,tree-list,pivot,core,behavior,react}`):
  - `packages/grid/src/lib/grid/grid.ts` inputs/outputs, `packages/grid/src/lib/columns/*` column inputs.
  - `packages/behavior/src/lib/grid/grid-options.ts`, `grid-editing-state.ts`, `grid-columns.ts`, `grid-keyboard-moves.ts`.
  - `packages/behavior/src/export-excel.ts` / `export-pdf.ts` (shared XLSX/PDF builders).
  - `packages/core/src/lib/data/load-options.ts` (FilterOperator, SummaryType, GroupInterval), `packages/core/src/lib/pivot/pivot-types.ts`.
  - `packages/grid/src/lib/pager/pager.ts`, `packages/grid/src/lib/filter-builder/filter-builder.ts`.
- Zero hits (so treated as Missing): `rangeSelection|cellSelection|CellRange`, `fillHandle`, clipboard `paste`, grid `undo/redo`,
  `pinnedRow|frozenRow|stickyRow`, grid `colSpan/rowSpan/mergeCells`, `conditionalFormat`, `window.print`, async validators,
  `sparkline`, `autoFit|bestFit`, `rowNumber`, `statusBar`, `toolPanel|sidebar`, `filterMenu|columnMenu`, `cellClass|rowClass` (grid),
  `allowGrouping|showInColumnChooser`, `scrollToColumn`, `chart` in pivot/grid sources, locale message packs.

### OGE strengths already shipped (do not re-build)

Local/custom/OData data sources; server-side sort/filter/page/group/summaries; deferred group loading; push/live updates +
`highlightChanges`; paging (+"all", compact/adaptive pager); row + column virtualization, infinite scroll, remote windowed
virtual scroll (1M rows), measured variable row heights; single/multi sort, `calculateSortValue`; filter row + operator menu,
header filter (search, date-year tri-state), search panel with `<mark>` highlight, filter builder + filter panel,
`[(filterValue)]`, `calculateFilterExpression`; group panel DnD, multi summaries, custom summary, group footer summaries,
expand/collapse all; resize/reorder/pin/chooser (anchored, drag reorder), banded headers, lookup + cascading lookup,
calculated columns, adaptive column hiding (`hidingPriority`), command buttons, templates (cell/header/edit/detail/row/no-data),
word wrap; selection single/multi/checkbox, select-all modes, deferred selection, focused row/cell; APG keyboard nav
(RTL-aware), keyboard resize (Alt+Arrow), keyboard column/row/group move (Ctrl+Arrow), live announcements (sort/row count/page/
expand/selection/validation); editing cell/row/batch/form/popup, sync validators, confirm delete, row drag reorder; RTL,
striping, load panel, toolbar slot, row/header context menus; state persistence (`stateKey`, sync/async storage, state
sanitizer); CSV/XLSX/PDF export (scopes all/page/selection, `customizeCell`); master-detail; themes (light/dark/bootstrap/
tailwind/high-contrast, forced-colors, reduced motion, 24/44px targets); full imperative API + DX-style event surface.
Tree list: self-ref + nested data, lazy load with remote match discovery, recursive tri-state selection, DnD reparent,
Excel outline export. Pivot: 4 areas, intervals, display modes/running totals, sortBySummary, include/exclude filters,
field chooser (instant/onDemand), drill-down, 2-axis virtualization, remote store, XLSX merged headers, full keyboard map.

## Top 15 gaps for this family (prioritized)

1. **Cell range selection + range copy (TSV w/ headers) + multi-cell paste from Excel** (grid, then tree-list/pivot). Biggest
   "Enterprise" differentiator in AG/SF/MUI/Kendo; OGE is row-selection only. H / L.
2. **Rich XLSX export**: group rows with outline levels, group + total summaries, banded headers, freeze panes, column widths and
   per-cell style/numFmt in `customizeCell`. Current grid export is flat. H / M.
3. **Pivot chart binding** using `@oge-ui/charts` (follow expand/collapse, measures as series). Last "Missing" row in ROADMAP; now
   unblocked. H / M.
4. **Pinned/frozen rows (top/bottom) + sticky group rows**. Kendo, AG, MUI, SF all ship it. H / M.
5. **Declarative row/cell styling hooks** (`rowClass`, `cellClass`, `cellPrepared`/`rowPrepared` events) + simple conditional
   formatting rules. H / S.
6. **Excel-style column filter menu** (values checklist + condition filters in one popup, date tree year > month > day). H / M.
7. **Async validation** (Angular `AsyncValidatorFn` / Promise rules in React) with pending indicator + validation summary. H / S.
8. **Built-in localization packs** (at least de/fr/es/tr/ja/zh/pt for all `Oge*Messages`). H / S–M.
9. **Adaptive detail row / mobile stacked layout** so `hidingPriority`-hidden columns stay reachable on phones. H / S–M.
10. **Tree List summaries/aggregates** (total + recursive node aggregates). H / M.
11. **Pivot calculated measures + value/Top-N/label filters**. H / M.
12. **Column auto-fit** (double-click separator, `autoFitColumns()`, `columnAutoWidth`) + cell/header overflow tooltips. H / S.
13. **AI assistant integration** (natural language → `GridStateSnapshot`/`applyState`, optional AI columns). Every paid competitor
    shipped one in 2025–26. M-H / M.
14. **Row and column spanning / cell merging**. M / M.
15. **Cross-component row drag & drop** (grid ↔ grid, tree ↔ tree, grid → tree, external drop zones) + pager first/last + go-to-page
    polish. M / M (pager S).

Honourable mentions: fill handle and undo/redo; per-column capability flags (`allowGrouping`/`showInColumnChooser`…);
datetime + multi-value (TagBox) columns; custom group intervals; tree-list and pivot PDF export; pivot layout modes
(compact/tabular, totals position); standalone filter builder with custom operations; print.
